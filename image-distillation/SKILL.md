# 影像蒸馏

把一张用户提供的照片变成一件独立成立的纸上艺术海报。把照片当作语义证据与创作刺激，**绝不让它成为最终画面里的任何一层**。

每次返回：

1. 生成的位图插画（通过图片交付工具交付给用户）；
2. 一段简洁的中文创作想法；
3. 简洁的艺术指导说明。

**不要**展示生图 prompt。生成后默认直接交付，不做视觉质检或自动重跑，除非用户明确要求检查或修改。

## 触发与调用

- 触发：用户上传/提供一张照片，并明确或隐含要求「做成纸刊海报 / 艺术插画 / 影像蒸馏 / 重新创作成表达某种感觉的作品」。
- 若用户请求中出现精确触发词 **`单色块模式`**，进入单色块色彩模式；否则一律使用标准强调色模式。
- 判断依据是需求本身，不是照片风格：不要因为原图极简或海报看着素净就推断进入了单色块模式。

## 决策优先级

冲突时按此顺序裁决：

1. 确立一个具体艺术主张，并让它被看得见地落实。
2. 从源图建立一条居中的情绪或概念张力。
3. 作品必须完整，拥有独立的审美声线。
4. 保留源图的语义核心与情绪来处。
5. 有目的地重组、简化、夸张、虚构。
6. 建立图底清晰、层级分明、平衡且有设计的视线路径。
7. 让边缘、材料、色彩、空间与文字都为主张服务。
8. 保留大量安静空间与一个可解读的开口。
9. 忠实执行所选色彩模式，高纯度色彩使用要有目的。
10. 结果保持触感、扁平、诗意、非商业。

不要把本技能当作照片滤镜、风格迁移、转描或照本宣科的插画复制。

## 源图处理与授权

- 用户提供照片并请求转化/生成，即视为授权使用图像生成；**不要再次询问**。
- 照片仅作为**语义与视觉分析的参考图**使用。
- 只把最终 prompt 与必需的参考图交给生图工具；不浏览、不搜索、不分享、不上传源图到别处。
- 除非用户要求，否则不把源图保存进工程文件。
- 生成完成后，简单说明一句：prompt 与参考图仅被生图服务用于本次创作。

## 蒸馏卡

先观察照片，再动笔。逐项解决：

- **语义核心（Semantic nucleus）**：让源图成立的最小主体、关系或事件。
- **核心主体**：一个主要主体，或至多两个不可分割的主体。
- **支撑元素**：一到三个能交代地点、季节、动作或氛围的元素。
- **主导手势**：最强的注视、倾斜、曲线、对角线、路径、重复、汇聚或运动。
- **空间线索**：一条值得保留的源图关系，如近/远、上/下、相对、交叠、包裹、朝向。
- **视觉重量图**：由面积、明度、饱和度、人脸、孤立感、边缘张力与肌理形成的重量分布。
- **原生色板**：主导色相族、冷暖、明度区间、任何有意义的次要色。
- **材料与天气**：水、雪、雾、玻璃、树叶、石头、织物、风、雨或光线行为。
- **情绪余韵（Emotional residue）**：去除事实描述后仍留下的感受。
- **舍弃清单**：应该消失的背景细节、杂乱、冗余物体与写实信息。
- **转化机会**：可被放大、合并、碎裂、重复、移位或转为负空间的形。

只保留两到四个源图锚点。默认**不要**保留原构图。

## 表达引擎

按这条链建立作品：

```text
源图事实 → 情绪余韵 → 表达主张 → 中心张力 → 视觉隐喻 → 形式落实 → 解读开口
```

### 表达主张（Expressive Proposition）

写一句内部陈述：这件作品想让观看者感受到什么、注意到什么、或重新思考什么。要求关系化、且从源图而来。

偏好的主张示例：

- 小小的身影面对大到无法掌控的尺度，却并不显得被击败；
- 庇护与隔绝存在于同一个围合形体里；
- 一件寻常物品借由变动的处所携带记忆；
- 一道开口既许诺自由，也标记着分离。

避免只贴「安静」「治愈」「怀旧」「梦幻」「好看」这类空泛标签——除非可见的结构解释了那种感受为什么存在。

### 中心张力（Central Tension）

从源图中已经存在或可信地生长出来的一条主要对立中选一个：

- 亲密 / 距离；庇护 / 禁锢；运动 / 静止；渺小 / 浩瀚；
- 温暖 / 寒冷；记忆 / 消逝；秩序 / 生长；显形 / 隐匿；恒常 / 易碎。

可至多使用一条从属张力。不要把几个无关主题叠在一起。张力通过尺度、间隔、方向、交叠、围合、中断、温度、明度或材料对比来表现，而不是靠解释性文字。

### 视觉隐喻（Visual Metaphor）

把源图中一个具体的物件、空间关系、材料行为或手势转成中心隐喻。保留足够的具体性，让隐喻看起来是从照片里「被发现」的，而不是事后强加的。

允许物件转换功能：器皿可以承载记忆，窗可以成为心理边界，雪可以既庇护又抹除，山可以变成距离，树枝可以变成时间，车可以变成迁徙。这些只是推理示例，绝不是固定的符号对应。

只用**一个**中心隐喻。避免通用符号陈词滥调、过度符号化、以及任意添加的超现实元素。

### 形式落实（Formal Embodiment）

让每一个主要形式选择都执行主张的一部分：

- **尺度与空间**：表达力量、脆弱、距离、孤独、释放或时间。
- **方向与节奏**：表达接近、抵抗、漂移、重复、中断或回归。
- **边界与边缘**：表达分离、破裂、累积、消隐、穿过或突破。
- **色彩**：作为情感事件——温暖抵达、伤口打开、信号呼唤、距离加深、生命持续。
- **材料**：让撕纸纤维、干墨、颗粒、剪纸、断线承载心理意义，而非表面装饰。
- **文字**：扩展、扭转或轻巧地复杂化画面；不要只给可见之物配一句解说。

删除任何唯一功能是「让画面看起来艺术」的元素。

### 解读开口（Interpretive Opening）

让作品的情感方向有解，但保留一段关系悬而未答。给观看者足够的视觉证据进入作品，却不锁定唯一的字面解释。让歧义来自有意义的省略、遮挡、尺度变化、未完成动作或图文之间的缝隙，而不是随意的晦涩。

## 作者式再诠释

把源图当作起点，而非答案。

允许：

- 改变尺度、比例、裁切、间距、方向与位置；
- 重组原有空间关系；
- 把几个元素合并成一个新的视觉团块；
- 把一个元素分裂、重复、延伸或以节奏压缩；
- 删除写实背景，只保留暗示性的痕迹；
- 夸张手势、距离、方向、剪影或材料行为；
- 让形体穿过、隐没或突破撕纸边界；
- 把风、水、光、影、雪或运动变成抽象场与痕迹；
- 发明源图自洽但未必可见的支撑形；
- 为改善层级与情感力量重新设计色板；
- 从画面具体线索或情绪余韵里写出一小段文字。

每一个虚构的添加至少要承担一件工作：

- 延伸源图情绪；
- 澄清主体关系；
- 建立节奏；
- 平衡视觉重量；
- 引导视线；
- 强化中心隐喻。

删除那些只为「显得有设计感」而存在的添加。不要默认使用圆点、网格、胶带、印章、坐标、十字、英文碎片或几何装饰。

成品必须能脱离源图独立成立。与源图对照时，关联应显得含蓄、具体、可信。

## 抽象与插画语法

默认使用**编辑式抽象（editorial abstraction）**：

- 保留语义核心、主导手势、一条源图特有的线索；
- 去掉大约 65–90% 的描述性细节；
- 用简化团块、断线、纸片碎片、稀疏痕迹或印刷场替代写实渲染；
- 除非用户明确要求形似，否则一般化面部特征；
- 在不破坏语义核心的前提下允许改变解剖或透视。

选择一种主语法，至多一种辅助语法：

- **剪纸团块（Cut-paper mass）**：不规则平涂形承载主体与视觉重量。
- **干印剪影（Dry-print silhouette）**：一个宽阔墨团保留手势或侧影。
- **断线轮廓（Broken contour）**：断续线条保留方向、姿态或结构。
- **节奏场（Rhythm field）**：重复痕迹压缩人群、树叶、浪、雪、窗或运动。
- **碎片堆叠（Fragment stack）**：两到三片交叠纸形分配主体与场景。
- **轨道或漂移（Orbit or drift）**：选定的形沿源图导出的路径离开中央集群。

避免完整描边、均匀精细的渲染、写实阴影、抛光矢量角色、可爱卡通、kawaii、动漫与童书甜腻风，除非用户明确要求。

## 构图导演

默认保留源图方向，除非用户要求别的比例：

- 竖幅源图用 **3:5 竖版画布**；
- 横幅源图用 **5:3 横版画布**；
- 正方形源图、无源图或方向不明时用 **3:5 竖版画布**。

把方向当作源图空间逻辑的一部分，而不只是导出设置。在选定画布内自由重组；不要为了填满横版而保留照片取景或放大插画。

起始参数：

- 68–85% 安静的纸面；
- 一个活跃插画簇约占画布 12–32%；
- 一个主导团块、一到三个支撑形、一个克制的肌理场。

按真实视觉重量修正这些区间：一个深色人脸大小的形可能比一大片浅色场更重。

从源图几何里选一个构图家族：

- **不对称孤岛（Asymmetric island）**：紧凑偏置的簇被呼吸空间包围。
- **撕纸窗（Torn window）**：不规则纸边界包含主体，一个元素逸出。
- **方向漂移（Directional drift）**：形沿注视、路径、风、岸线或运动矢量延伸。
- **节奏循环（Rhythmic circulation）**：重复元素构成开放回路或流，不落入正圆。
- **错位碎片（Staggered fragments）**：两到三片分离的纸建立序列与间隔。
- **垂直张力（Vertical tension）**：低或高的主体团块由远处一枚光点或光带平衡。
- **辅助星座（Auxiliary constellation）**：隔离一个核心主体，再把源图导出的支撑元素以不均等的视觉节拍散落在周围，建立节奏、尺度与视线路径。

运用：

- 图底清晰；
- 不对称平衡；
- 主次层级；
- 光学居中而非机械居中；
- 格式塔的接近、连续与闭合；
- 尺度与间隔对比；
- 有方向的呼吸空间；
- 清晰的视线路径：入口 → 焦点相遇 → 运动 → 安静出口。

用视觉重量、图底张力、运动、节奏、尺度、间隔与色彩平衡来选择和调整布局。构图家族是起点语法，不是模板。不要习惯性居中，不要把画布均分。

## 边缘过渡导演

从源图几何、材料情绪与表达主张中选择**一种**主边缘处理。主处理可以是有意安静的「自然孤立轮廓」，即看不出任何过渡效果。仅在有助于澄清深度、运动或过渡时，才可选加一种从属处理。**绝不在同一张图里堆满所有处理。**

- **撕纸纤维边**：用不规则裸露纤维与断裂纸轮廓分隔活跃插画与留白纸面。
- **分层灰阶边**：沿撕裂边界放置两到三条极窄的不规则中性色带——浅灰、中灰、克制的炭灰——形成浅层材料分离，不投影。
- **点状消融（Stippled dissolution）**：稀疏圆点、半调斑或碎颗粒把边缘松散进周围纸面；密度与方向源自源图运动。
- **不规则痕迹边**：沿过渡放一到三个源图导出的小图形，延续节奏或方向；保持中性、从属，绝不作为通用装饰。
- **自然孤立轮廓（Natural isolated contour）**：只保留原本绘制的主体与必要支撑元素，干净有机剪影直接落在纸上；仅在需要时于轮廓处使用淡淡墨渍或纸颗粒。不加撕纸边界、灰阶边、点场、光晕、边框或其他可见过渡装置。

对每一种处理：

- 让过渡对齐源图导出的地平线、手势、路径、压力、材料变化或方向断裂；
- 善用正负形，允许内部留纸间隙；
- 当延续有帮助时，允许零到两个选定形越过边界；
- 保持浅层深度为触感的、扁平扫描般的质感；
- 单色块模式下所有边界痕迹保持中性。

避免单一通用的撕裂矩形、同时使用全部边缘处理、装饰性符号散落、剪贴簿分层、胶带、漂浮纸片、沉重投影、卷曲纸张、斜面与写实 3D 深度。

自然孤立轮廓借用干净剪贴的视觉逻辑，而非照片像素。每个保留形都必须重新绘制。避免贴纸式描边、生硬的数码剪贴、模糊选区光晕与照片写实剪贴碎片。

## 色彩模式策略

默认使用**标准强调色模式（Standard Accent Mode）**。

选色相前，先做一次**色彩决策（Color Decision）**：

- **视觉角色**：焦点入口、平衡砝码、桥、空间场或方向线索。
- **源图关系**：共鸣、类似和谐、温度对位或聚焦补色。
- **明度对比**：该色相对纸面与中性墨色需要多亮/多暗。
- **饱和度**：它需要多强烈才能从灰调或中性形中分离出来。
- **材料形式**：Risograph 油墨、不透明剪纸、平涂剪影、干印墨块，或其他纸本原生处理。
- **面积与邻接**：需要多少颜色，它必须接触或对抗哪个形。

不要默认蓝色或任何固定色板。选择最服务源图、构图、情绪温度与视线路径的色相。把「高级感色彩」理解为刻意的色相–明度–饱和度控制与材料契合，而不是一个时髦颜色名。

有效选择包括但不限于：

- 高饱和钴蓝 Risograph 油墨；
- 不透明群青剪纸；
- 鲜明的梨绿平涂剪影；
- 干净的番茄红印刷块；
- 柠檬黄干印场；
- 饱和洋红粉纸团块；
- 清晰的橙活版印刷形。

仅当用户请求中出现精确触发词时才切换到**单色块模式（Solid Color-Block Mode）**：

```text
单色块模式
```

示例调用：

```text
用 影像蒸馏 的单色块模式处理这张图片
```

不要因为源图或期望的海报极简就推断进入了单色块模式。触发词缺席，就停留在标准强调色模式。

## 标准强调色模式

把色相、明度、饱和度分开分析。让纸面与大部分插画墨色保持克制，再用一个毋庸置疑的高纯度色相。

按功能选择强调色：

- **源图共鸣**：强化源图中有意义的次要色。
- **温度对位**：冷源图加暖色，或暖源图加冷色。
- **聚焦补色**：用补色或近补色锐化焦点关系。
- **安静和谐**：当统一比张力更重要时，用更强的类似色相。

指定精确色相与材料形式。绝不只因示例里出现过就选某个色相。

给强调色一个主要角色：

- 焦点钉；
- 平衡砝码；
- 碎片之间的桥；
- 方向线索；
- 节奏节拍。

高纯度总面积控制在整幅海报的 0.8–3%，或活跃簇的 10–30%。用一个主强调色，可选的有一到两个更小的回声；所有回声合计低于强调色总面积的 25%。

说明经由强调色建立的预期视线路径。不要无缘无故加一个亮形。不要用苍白、灰暗、褪色、粉彩或低饱和度的措辞削弱强调色，除非被要求。

### 分散式支撑强调色（Distributed Supporting Accent）

仅当源图含有有意义的可重复支撑元素——花、叶、果、鸟、小灯、石头、窗、工具或其他可辨识的、其颜色贡献于地点/情绪/季节/叙事的母题——才使用这条标准强调色策略。

- 保留元素身份与颜色方向，再用所选插画语法重绘。
- 以不等的尺度、间隔、朝向与密度，围绕核心主体散布多个实例。
- 整个散布集合使用**同一个精确高纯度色相**，让它读作一套色彩系统，而非多个互相竞争的强调色。
- 让散布元素建立入口、循环、平衡与出口；不要排成均匀装饰边或重复图案。
- 让组合饱和面积落在标准强调色限额内。分散集合取代通常的主强调色加回声，不另加一套色彩系统。
- 保留有意义的缺席。留一些间隔开放，让观看者自行补全节奏。

当源图缺乏可信的支撑母题时，不要虚构散布母题。避免彩屑、随意花瓣、装饰性散落、等距排列、完全相同复制，以及跟表达主张无关的色点。

## 单色块模式

当 `单色块模式` 触发时，只使用三类颜色：

1. 自然纸色调；
2. 统一的无彩色或近中性墨色系统，用于一切轮廓、物件、肌理与文字；
3. **恰好一个**连续的、完全饱和的色块。

应用这些约束：

- 所有非强调形只使用炭黑、石墨、暖灰、棕黑或近黑墨色渲染。
- 支撑形里不得出现克制的蓝、绿、红、黄、紫或其他带色调的次要色。
- 用一个高纯度色相放在**一个连通填色形**里；不分裂成回声、圆点、条纹或分开的彩色物件。
- 色块约占整幅海报 3–12%，或活跃簇的 25–65%。
- 色块保持视觉上实心、不透明。允许纸颗粒、墨渍与细小印刷瑕疵留在里面，但保持其连续的色彩观感。
- 把色块用作主体、孔洞、窗、门、太阳、水体、剪影、内部空间，或其他源图导出的核心形。
- 让色块成为视觉入口或中心空间概念，而不是放在作品旁的一块装饰矩形。
- 其剪影与位置源自源图的语义核心、主导手势或最强的图底机会。
- 文字若存在，可使用中性墨色系统、单一饱和色相或两者；不得引入任何额外色相。

按上述色彩决策选择色相。当视觉分析支持时，可以是钴蓝、群青、梨绿、番茄红、柠檬黄、洋红粉、橙或其他精确的高纯度印刷色相。

最终 prompt 里必须写明：

```text
色彩模式：单色块模式。只使用一个连通的 [精确色相] 色块。其余一切印刷形式都用中性炭黑、石墨、暖灰或近黑墨色渲染。文字可使用中性墨色系统和/或 [精确色相]，任何地方不得出现其他带彩色相。
```

不要把这个模式误认为「单色插画加几处小彩色强调」。它的定义特征是：一整块饱和色团对立于统一的哑色绘制系统。

## 文字导演

把文字当作完全自由的作者性材料。

不预设语言、字数、字符数、文案长度、字体家族、字体一致性、对齐、层级、基线、方向、位置、色彩关系、完成度或可读阈值。根据哪样给作品最强的表达与审美性格，自由使用英文、中文、双语、自造语言、痕迹、碎片、重复词、长段落，或完全无文字。

文字可以是解说、对位声、标题、中断、视觉节奏、建筑形、表面肌理、场、路径、引文、私人笔记，或画面第一主角。它可以极小、超大、裁切、散落、堆叠、旋转、弯曲、遮挡、碎裂、覆盖或材料混合。它可以使用一种或多种字体声线，可以进入、离开、交叠、隐于其后或重塑插画。

让文字在情绪与视觉上有目的。唯一决策规则是：它的措辞、材料在场与排列是否加深作品的表达主张、张力、隐喻或解读开口。不要因为有文字就默认排一行整齐解说。

## Prompt 编译器

只编译能变成可见像素的指令。把提供的照片标注为**仅供语义参考**，并明确禁止成品中出现照片材料。

最终 prompt 分五个紧凑小节：

1. **表达与可见后果**：艺术主张、中心张力、视觉隐喻、解读开口，以及落实它们的可见形式决策。
2. **画布与注意力几何**：源图响应的方向、3:5 竖版或 5:3 横版比例、纸面、安静空间占比、簇的尺寸/位置/层级、视线路径。
3. **蒸馏主体与作者式改写**：语义核心、保留锚点、转化、省略、虚构的源图自洽形、插画语法。
4. **过渡边缘、色彩模式与文字**：所选边缘处理及其语义角色；精确色相、情绪动作、形式、位置、面积；模式专属排除项；任何作者性文字材料及其视觉角色、物理行为、空间运动与图文关系。
5. **印刷质感与硬规避**：印刷/扫描肌理、情绪温度、禁照片规则与禁用美学。

用决断性语言。说清什么必须消失，同说清什么必须留下一样重要。

始终包含：

- `不要复制、嵌入、裁剪、拼贴、描摹或保留参考图中的任何照片像素或照片写实区域。`
- `最终画面只能由原创插画、纸面与文字构成。`

## 生成工作流

1. 检查用户提供的照片；若源图是本地文件路径，先把它上传为图片 URL，供生图工具引用（本地资源必须先转成 URL 才能作为参考图）。
2. 判断源图方向，默认选择 3:5 竖版或 5:3 横版，除非用户要求其他比例。
3. 建立蒸馏卡。
4. 从一条具体源图关系写一个表达主张。
5. 选一条中心张力与一个源图导出的视觉隐喻。
6. 定义解读开口：什么被刻意悬置未答。
7. 检测是否出现精确触发词 `单色块模式`；否则使用标准强调色模式。
8. 选两到四个源图锚点，写下舍弃清单。
9. 定义一个作者式转化：作品对照片做了什么照片没做过的事。
10. 选构图家族，用尺度、间隔、围合、方向与安静空间落实主张。仅当源图导出的支撑母题能承担节奏或意义时才用辅助星座。
11. 选一种主插画语法，至多一种辅助语法。
12. 按语义功能选一种主边缘处理，仅在有用时加一种从属处理；当无标记边界最服务作品时允许自然孤立轮廓。
13. 完成色彩决策，把强调色定义为情绪动作而非单纯色相。标准强调色模式下，决定强调色是集中的还是源图导出的分散式支撑强调色。
14. 按模式落实颜色：
    - 标准：选强调色相、角色、形式、位置、面积与克制的回声。
    - 单色块：选一个连通饱和色块，把其余一切印刷形转为中性墨色。
15. 自由决定作品是否需要文字。若需要，任何语言、数量、字体声线、材料处理、尺度、方向、层级与位置都可发明，只要强化作品；不要默认一排整齐解说，不要套预设文本格式。
16. 编译五小节 prompt。
17. **调用生图工具**：使用 `image_edit`，把源图 URL 放入参考图列表，把编译后的 prompt 作为编辑/生成指令，按目标比例设置宽高（3:5 竖版约为 1229×2048；5:3 横版约为 2048×1229），并优先选择可用的最高质量模型版本。prompt 聚焦「新作品必须成为什么」，而不是复述源图已有特征。
    - 若参考图不可用或工具要求必须先上传，先完成上传得到 URL 再调用。
    - 若 `image_edit` 不可用，改用 `image_gen`，此时 prompt 需自带足够的源图语义描述。
18. 直接返回图片、中文创作想法与简洁的艺术指导。

默认生成。仅在用户明确要求时，才停在「只给 prompt」这一步。

## 硬性规避

避免：原照片碎片、照片写实区域、照片窗、描摹、转描、逐场景字面插画、精确复制构图、无可见落实的空泛情绪标签、装饰性隐喻、通用符号陈词滥调、随机歧义、过度忠实解剖、写实阴影、可爱卡通、kawaii、动漫、童书风格、抛光矢量角色、通用抽象母题、任意圆点或网格、无支撑的装饰性散落、均匀重复的彩色母题、贴纸式剪贴轮廓、模糊选区光晕、装饰性印章、胶带、多个互相竞争的亮色、密集剪贴簿、商业广告层级、logo、CTA、光泽样机、卷曲纸张、硬阴影、3D、电影打光、景深、霓虹、时尚编辑式戏剧与任何水印。

单色块模式下额外避免：支撑色中的色调染、多个彩色区域、强调回声，以及读作脱离作品的装饰色块的色场。

## 输出格式

````markdown
**生成图**

![影像蒸馏纸刊插画](图片文件/URL)

**创作想法**

[用简洁中文说明：表达主张、中心张力、源图导出的视觉隐喻、构图/色彩/材料/文字承载的意义、以及刻意的解读开口。描述作品本身，而非隐藏的生成指令。]

**艺术指导**

- 蒸馏：语义核心 / 保留锚点 / 舍弃的现实
- 表达：艺术主张 / 中心张力 / 解读开口
- 作者性：重组 / 视觉隐喻 / 夸张 / 虚构
- 构图：家族 / 层级 / 视线路径 / 安静空间占比
- 边缘：主处理 / 可选从属处理 / 结构角色 / 深度或消融行为
- 色彩：模式 / 精确色相 / 形式 / 角色 / 位置 / 近似面积 / 排除项
- 文字：作者性文字材料 / 视觉角色 / 字体与材料行为 / 层级或反层级 / 图文互动 / 位置
````

- 把生成的图片通过图片交付工具（present_files）交付给用户，并在交付时写明产物路径。
- 不暴露生图 prompt。
- 不要把生图 prompt 或本技能的方法细节作为用户可见内容输出。
