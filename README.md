# Agent Skills ｜ 可靠、可控、可复用的 AI 能力库

> 作者：hxw ｜ 工作室：https://18.cx

## 📌 项目简介

**Agent-Skills** 是一套面向 AI Agent 设计的轻量化、标准化、可落地的**通用技能包**，旨在解决 Agent 能力零散、执行不稳定、复用成本高、行为不可控等问题，将零散的工具调用、任务流程与行为规范封装为标准化技能单元。

本仓库聚焦 **可靠性、可控性、可复用性、可扩展性** 四大核心目标，让 AI Agent 告别 "随机发挥"，具备稳定、规范、可持续迭代的执行能力，可灵活适配自动化任务、智能助手、业务流程 Agent 等各类场景。

技能包采用 "即插即用" 的设计理念，每个技能独立封装、统一规范，Agent 可通过读取技能目录下的 `SKILL.md` 自动发现并挂载能力，无需修改核心框架。目前已覆盖**工程建设监理文档**、**建筑施工知识库**、**标准图集知识库**与**创意设计**四大领域，后续将持续扩展更多行业场景。

## ✨ 核心优势

相较于零散的 Agent 能力实现方式，本技能包具备四大核心特性：

* **✅ 可靠（Reliable）**：内置异常捕获、参数校验、重试机制、结果校验，规避调用失败、参数错误、结果不稳定等常见问题，任务执行成功率大幅提升。

* **✅ 可控（Controllable）**：统一行为规范、权限管控、日志溯源、流程约束，所有技能执行可追溯、可拦截、可配置，杜绝越权、乱执行、无效操作。

* **✅ 可复用（Reusable）**：技能模块化、标准化封装，解耦业务逻辑与 Agent 核心逻辑，支持一键引入、跨项目复用、组合拼装复杂任务。

* **✅ 可扩展（Extensible）**：统一的技能注册、挂载、调用规范，新增技能无需改造核心框架，快速迭代适配各类新场景。

## ✅ 可靠性保障机制

为有效解决 Agent 执行不稳定问题，文档生成类技能内置全套保障机制：

* **参数强校验**：自动校验入参类型、长度、合规性，拒绝无效调用

* **异常自动降级**：执行报错自动捕获，返回规范错误信息，避免任务中断

* **重试容错机制**：网络波动、临时报错自动重试，提升任务成功率

* **全链路日志**：记录每一次技能调用的入参、出参、耗时、状态，可溯源排查问题

* **行为可控约束**：限制高危操作、配置权限白名单，避免违规执行

> 创意设计类技能基于 AI 生图工具驱动，可靠性由生图工具与技能工作流中的质量检查环节共同保障；知识库/图集类技能的可靠性由「全文索引 + 关键词检索 + 页码出处 + 原图/原文复核」机制共同保障。

项目采用模块化设计，每个技能独立成目录，结构清晰、易于维护与扩展：

```
.

│   ├── SKILL.md                     # 技能说明文档
│   ├── assets/                      # 标准模板（监理日志.docx）
│   └── scripts/                     # generate_diary.py 日志生成脚本
├── supervision-notice/              # 监理通知单
│   ├── SKILL.md                     # 技能说明文档
│   ├── assets/                      # 标准模板（监理通知单.docx）
│   └── scripts/                     # generate_notice.py 通知单生成脚本
├── building-construction-handbook/  # 建筑施工手册知识库
│   ├── SKILL.md                     # 技能说明文档
│   ├── references/                  # 41 章全文文本 + 分级目录索引 INDEX.md
│   └── scripts/                     # kb_search.py 检索 / 知识库重建脚本
├── 22G101/                          # 混凝土结构施工图（标准图集知识库）
│   ├── SKILL.md                     # 技能说明文档
│   ├── assets/                      # 4 本官方图集 PDF（22G101-1/2/3、23G101-11）
│   ├── references/                  # 4 本图集全文索引 txt
│   └── scripts/                     # search_atlas.py 检索/页码换算/渲染原图
├── photo-collage/                   # 实景拼贴
│   └── SKILL.md
├── image-distillation/              # 影像蒸馏
│   └── SKILL.md
├── morandi-movie-poster/            # 莫兰迪电影海报
│   └── SKILL.md
└── README.md                        # 项目说明文档
```

### 技能目录规范

文档生成类技能遵循统一的三段式结构，便于 Agent 自动发现与调用：

| 目录 / 文件    | 说明                                                       |
| ---------- | -------------------------------------------------------- |
| `SKILL.md` | 技能元信息（name、description）与完整使用文档，Agent 据此判断触发时机与调用方式           |
| `assets/`  | 模板文件、参考素材等静态资源（文档生成类技能必需）                                |
| `scripts/` | 技能核心执行脚本，接收命令行参数并输出结果（文档生成类技能必需）                           |

> - **创意设计类**技能基于 AI 生图工具驱动，无需 `assets/` 与 `scripts/` 目录，仅通过 `SKILL.md` 中的完整工作流指导 Agent 执行。
> - **知识库类**技能（建筑施工手册、22G101 图集）使用 `references/` 目录存放分章全文与章节索引，通过 `scripts/` 中的检索脚本按关键词定位内容并返回页码出处，供 Agent 查询后引用作答。

## 🚀 快速开始

### 环境要求

* Python 3.8+（文档生成类与知识库类脚本）
* 依赖包：`python-docx`（文档生成类）、`pymupdf`（图集/知识库类，渲染与重建）

### 1. 克隆仓库

```
git clone https://github.com/881000/skills.git
cd skills
```

### 2. 安装依赖

```
pip install python-docx pymupdf
```

各类型技能依赖说明：

* **文档生成类**（监理日志、监理通知单）：仅需 `python-docx`。
* **知识库类**（建筑施工手册）：日常检索 `kb_search.py` 仅依赖 Python 标准库，无需额外安装；仅重建知识库时需要 `pymupdf`。
* **图集类**（22G101）：`search_atlas.py` 的检索、页码换算与渲染原图均依赖 `pymupdf`。
* **创意设计类**：无需安装任何依赖，由 Agent 调用 AI 生图工具执行。

### 3. 调用技能

#### 文档生成类（以监理日志为例）

```
python3 supervision-diary/scripts/generate_diary.py \
  -o 输出文件路径.docx \
  --project "XX工程项目" \
  --date "2026年8月30日" \
  --weather-am "晴" \
  --weather-pm "多云" \
  --temp-high "32" \
  --temp-low "24" \
  --construction "当日施工进展原始描述..." \
  --supervision "当日监理工作原始描述..." \
  --problem "当日问题及处理原始描述..." \
  --other "其他事项..."
```

长文本可写入文件后通过 `--xxx-file` 参数传入：

```
python3 supervision-diary/scripts/generate_diary.py \
  -o 输出.docx \
  --project "XX项目" \
  --date "2026年8月30日" \
  --construction-file ./施工内容.txt \
  --supervision-file ./监理内容.txt \
  --problem-file ./问题内容.txt
```

**多日期批量生成**（同一份 docx，按分页符逐日另起一页）：

```
python3 supervision-diary/scripts/generate_diary.py \
  -o 输出.docx \
  --entries-file ./多天日志.json
```

**按城市自动获取天气气温**（未填写任何天气/气温字段时自动触发，数据来自 Open-Meteo，无需 API Key）：

```
python3 supervision-diary/scripts/generate_diary.py \
  -o 输出.docx \
  --project "厦门XX大厦主体工程" \
  --date "2026年8月30日" \
  --construction "3号楼完成二层梁板混凝土浇筑..." \
  --supervision "对3号楼二层梁板浇筑进行旁站监理..."
```

监理通知单除直接传参与 `--content-file` 外，还支持 `--deadline` 自动追加整改要求段落、`--image` 附加现场照片（可多次指定，每页最多 6 张自动排版）：

```
python3 supervision-notice/scripts/generate_notice.py \
  -o 输出.docx \
  --project "XX项目" \
  --subject "钢筋绑扎质量问题" \
  --content "现场检查发现负二层钢筋绑扎间距不符合设计要求..." \
  --deadline "2026年9月5日" \
  --image ./现场照片1.jpg \
  --image ./现场照片2.jpg
```

所有文档生成类技能均支持：

* 命令行参数直接传入文本内容
* `--xxx-file` 参数从文件读取长文本
* 输出标准格式 docx 文件，可直接打开编辑

#### 知识库类（以建筑施工手册为例）

在支持技能的 Agent 环境中，直接提问建筑施工相关问题即可，例如：

> 防水混凝土的设计抗渗等级怎么定？

Agent 会按「索引定位章节 → 关键词检索 → 读取片段 → 引用出处」的工作流，在 `references/` 知识库中定位并作答。也可直接使用检索脚本快速定位：

```
python3 building-construction-handbook/scripts/kb_search.py 抗渗等级 --chapter 31
```

返回命中内容及对应 PDF 页码，便于回源核对。

#### 图集类（以 22G101 为例）

在支持技能的 Agent 环境中，直接提问混凝土结构施工图问题即可，例如：

> 受拉钢筋的基本锚固长度怎么确定？

Agent 会按「判定所属图集 → txt 关键词快查 → 按需渲染原图 → 汇总输出」的工作流作答。也可直接使用 `search_atlas.py` 检索定位、页码换算与渲染原图：

```
# 关键词检索定位页码（默认全图集，可 --atlas 指定分册）
python3 22G101/scripts/search_atlas.py --keywords "锚固长度"
python3 22G101/scripts/search_atlas.py --keywords "梁柱节点" "箍筋加密区" --atlas 22G101-1

# 渲染目标页原图（构造详图/数值表格以原图为准）
python3 22G101/scripts/search_atlas.py --render "22G101-1:88" --out-dir ./atlas_out

# 扫描版图集（23G101-11）内部页码 → PDF 页码换算
python3 22G101/scripts/search_atlas.py --map 23G101-11:7-1
```

#### 创意设计类（以实景拼贴为例）

在支持技能的 Agent 环境中，直接上传照片并描述需求，例如：

> 用实景拼贴技能把这张照片做成纸刊海报。

Agent 会自动读取对应 `SKILL.md` 中的工作流，完成场景分析、构图决策、prompt 编译与图片生成。

## 🔧 新增技能开发

本技能包支持快速扩展，新增技能遵循以下规范即可被 Agent 自动识别与调用：

1. **新建技能目录**：在仓库根目录下创建 `your-skill-name/` 文件夹（使用英文小写连字符命名）

2. **编写 SKILL.md**：包含 frontmatter（`name`、`description`）和完整使用文档，description 中明确触发关键词和适用场景

3. **放置资源**：文档生成类技能在 `assets/` 中存放模板、参考文件等静态资源

4. **编写脚本**：文档生成类技能在 `scripts/` 中实现核心逻辑，统一使用命令行参数接收输入

5. **遵循规范**：输出格式稳定、参数有默认值、异常有兜底，确保可靠执行

6. **添加作者信息**：在 SKILL.md 的 frontmatter 后、正文标题前添加作者引用块

7. **更新 README**：在「已包含技能」章节对应分类中新增一行，保持清单与实际目录同步

> 知识库类技能在第 3 步中改为在 `references/` 目录存放分章全文、索引等知识内容，并配套检索脚本（第 4 步）供 Agent 查询定位。
