# Agent Skills 技能包 | 可靠、可控、可复用 AI 能力库

## 📌 项目简介

**Agent-Skills** 是一套面向 AI Agent 设计的轻量化、标准化、可落地的**通用技能包**。旨在解决原生 Agent 能力零散、执行不稳定、复用成本高、行为不可控的问题，将零散的工具调用、任务流程、行为规范封装为标准化 Skill 单元。

本仓库聚焦 **可靠性、可控性、可复用性** 三大核心目标，让 AI Agent 告别"随机发挥"，具备稳定、规范、可迭代的执行能力，适配自动化任务、智能助手、业务流程 Agent 等各类场景。

技能包采用"即插即用"的设计理念，每个技能独立封装、统一规范，Agent 可通过读取技能目录下的 `SKILL.md` 自动发现并挂载能力，无需修改核心框架。目前已覆盖工程建设监理文档等领域，后续将持续扩展更多行业场景。

## ✨ 核心优势

相较于传统零散的 Agent 能力实现，本技能包具备四大核心特性：

- **✅ 可靠（Reliable）**：内置异常捕获、参数校验、重试机制、结果校验，规避 Agent 幻觉、调用失败、参数错误等常见问题，任务执行成功率大幅提升。
- **✅ 可控（Controllable）**：统一行为规范、权限管控、日志溯源、流程约束，所有技能执行可追溯、可拦截、可配置，杜绝越权、乱执行、无效操作。
- **✅ 可复用（Reusable）**：技能模块化、标准化封装，解耦业务逻辑与 Agent 核心逻辑，支持一键引入、跨项目复用、组合拼装复杂任务。
- **✅ 可扩展（Extensible）**：统一的技能注册、挂载、调用规范，新增技能无需改造核心框架，快速迭代适配各类新场景。

## 📂 仓库结构

项目采用模块化设计，每个技能独立成目录，结构清晰、易于维护与扩展：

```Plain Text
.
├── skill-name-1/             # 技能目录（每个技能一个文件夹）
│   ├── SKILL.md              # 技能说明文档（元信息、功能、参数、规则）
│   ├── assets/               # 模板与静态资源
│   └── scripts/              # 技能执行脚本
├── skill-name-2/             # 更多技能...
│   ├── SKILL.md
│   ├── assets/
│   └── scripts/
└── README.md                 # 项目说明文档
```

### 技能目录规范

每个技能包遵循统一的三段式结构，便于 Agent 自动发现与调用：

| 目录/文件 | 说明 |
|-----------|------|
| `SKILL.md` | 技能元信息（name、description）与完整使用文档，Agent 据此判断触发时机与调用方式 |
| `assets/` | 模板文件、参考素材等静态资源 |
| `scripts/` | 技能核心执行脚本，接收命令行参数并输出结果 |

## 🚀 快速开始

### 1. 克隆仓库

```Plain Text
git clone https://github.com/881000/skills.git
cd skills
```

### 2. 安装依赖

技能脚本基于 Python 开发，文档生成类技能统一依赖 `python-docx`：

```Plain Text
pip install python-docx
```

### 3. 调用技能

进入对应技能目录，按 `SKILL.md` 中的参数说明执行脚本即可。所有技能均支持：

- 命令行参数直接传入文本内容
- `--xxx-file` 参数从文件读取长文本
- 输出标准格式文件，可直接打开编辑

## 🔧 新增技能开发

本技能包支持快速扩展，新增技能遵循以下规范即可被 Agent 自动识别与调用：

1. **新建技能目录**：在仓库根目录下创建 `your-skill-name/` 文件夹
2. **编写 SKILL.md**：包含 frontmatter（`name`、`description`）和完整使用文档，description 中明确触发关键词和适用场景
3. **放置资源**：在 `assets/` 中存放模板、参考文件等静态资源
4. **编写脚本**：在 `scripts/` 中实现核心逻辑，统一使用命令行参数接收输入
5. **遵循规范**：输出格式稳定、参数有默认值、异常有兜底，确保可靠执行

所有技能自动继承统一的目录结构和调用约定，Agent 可通过读取 `SKILL.md` 自动发现并挂载新技能，无需修改核心框架。

## ✅ 可靠性保障机制

为彻底解决 Agent 执行不稳定问题，项目内置全套保障机制：

- **参数强校验**：自动校验入参类型、长度、合规性，拒绝无效调用
- **异常自动降级**：执行报错自动捕获，返回规范错误信息，避免任务中断
- **重试容错机制**：网络波动、临时报错自动重试，提升任务成功率
- **全链路日志**：记录每一次技能调用的入参、出参、耗时、状态，可溯源排查问题
- **行为可控约束**：限制高危操作、配置权限白名单，避免违规执行
