# 建筑标准速查技能

## 概述

本技能以 4 本官方图集 PDF 为内置依据，并支持用户上传的规范/规程 PDF（如《JGJ18-2012 钢筋焊接及验收规程》）作为补充查询来源。每次回答统一输出四部分：**原文**（逐字引用，不改写、不删减）、**内容摘要**（条理清晰、表述合理的要点归纳）、**来源引用**（图集号/规范编号 + 页码，含条文号或构造图号）、**总结**（本次查询核心结论的简明归纳）。查询内容全部来自内置图集与已导入规范，不凭空补充条文。

**高效检索采用「txt 快查 + PDF 出原图」混合方案**：

- `references/*.txt` 与 `references/specs/*.txt` 分别是图集与规范的全文索引，关键词检索**毫秒级返回**，无需每次打开大 PDF 逐页扫描（实测：txt 快查单本约 0.001s，PDF 逐页扫描单本约 0.4s，渲染单页约 0.2s）。
- 命中页码后，用 `atlas/` 下源 PDF 或 `specs/` 下规范 PDF **按需渲染目标页原图**，图纸/表格/条文以图为准，不受文字层噪声影响。

## 建筑规范扩展

用户上传的规范/规程类 PDF（如《JGJ18-2012 钢筋焊接及验收规程》）可导入本技能，作为图集之外的**补充查询来源**，与内置图集并列检索。导入即生效，回答时可与图集条文互相印证。

| 目录/文件 | 说明 |
|------|------|
| `specs/` | 规范/规程 PDF 原件（导入时复制） |
| `specs/manifest.json` | 规范登记表（编号：优先取规范编号如 JGJ18-2012，无编号时 SP-x；含标题、原文件名、页数、类型、导入日期） |
| `references/specs/` | 规范全文索引 `JGJ18-2012.txt` 等（与图集索引同格式，毫秒级快查） |
| `scripts/import_attachment.py` | 规范导入脚本 |

### 导入规范

```bash
# 导入用户上传的 PDF（编号自动提取：JGJ18-2012 …；无编号时自动分配 SP-1、SP-2 …）
python scripts/import_attachment.py "E:/下载/JGJ18-2012钢筋焊接及验收规程.pdf" --title "钢筋焊接及验收规程 JGJ18-2012"

# 指定编号 / 覆盖导入
python scripts/import_attachment.py "<pdf>" --id JGJ18-2012
python scripts/import_attachment.py "<pdf>" --id JGJ18-2012 --force
```

导入后可用 `python scripts/search_atlas.py --list-spec` 查看已导入规范清单。

### 检索规范

```bash
# 只检索规范 JGJ18-2012
python scripts/search_atlas.py --keywords "电渣压力焊" --spec JGJ18-2012

# 同时限定图集与规范
python scripts/search_atlas.py --keywords "焊接" --atlas 22G101-1 --spec JGJ18-2012

# 默认（不加 --atlas / --spec）：检索全部图集 + 全部规范
python scripts/search_atlas.py --keywords "电渣压力焊"
```

检索范围规则：`--atlas` / `--spec` **指定即限定**；两者都不指定时默认全库（4 本图集 + 全部规范）。规范命中结果标注「条文编号」（如 4.2.1），图集命中标注「图集内部页码」。

### 渲染规范原图

```bash
python scripts/search_atlas.py --render "JGJ18-2012:12" --out-dir ./out   # 渲染规范 PDF 第 12 页
```

命中后如需核对原文、表格、图样，一律渲染规范目标页原图，以图为准。

### 规范引用格式

回答引用规范内容时，统一标注：**规范名（编号）+ 条文号 + PDF 页码**，如：

> 钢筋焊接及验收规程 JGJ18-2012 第 4.1.2 条（PDF 第 19 页）：电渣压力焊应用于柱、墙等构筑物现浇混凝土结构中竖向受力钢筋的连接；不得用于梁、板等构件中水平钢筋的连接。

规范与图集条文冲突时，**两者并列给出**并注明来源，由使用者按适用场景取舍；不得用规范内容改写或覆盖图集原文。

## 工作流程

### 第 1 步：判定问题所属来源

| 问题主题 | 首选来源 | 备选 |
|------|------|------|
| 框架柱、剪力墙、梁、板 | 22G101-1 | 23G101-11 |
| 板式楼梯 | 22G101-2 | 23G101-11 |
| 独立基础、条形基础、筏形基础、桩基础 | 22G101-3 | 23G101-11 |
| 常见问题答疑、多图集综合问题 | 23G101-11 | — |
| 钢筋焊接工艺、焊接接头质量与验收、焊工考试、焊接安全 | 用户规范（如 JGJ18-2012） | 23G101-11 |

主题与规范相关时，先查规范，再与图集条文互证；主题不明时直接默认全库检索（图集 + 规范）。

### 第 2 步：按来源类型检索

**文字版图集（22G101-1 / 22G101-2 / 22G101-3）**

先用 txt 快查定位页码（默认走 `references/*.txt`，缺失自动回退 PDF 扫描）：

```bash
# 在全部图集中检索
python scripts/search_atlas.py --keywords "锚固长度"

# 指定图集、多关键词（任一命中即收录，按命中词数降序，优先同时命中页）
python scripts/search_atlas.py --keywords "梁柱节点" "箍筋加密区" --atlas 22G101-1

# 限定返回页数、调整上下文长度
python scripts/search_atlas.py --keywords "搭接长度" --atlas 22G101-3 --limit 5 --context 500
```

脚本返回命中页的 PDF 页码与图集内部页码。涉及**构造详图、数值表格**或需核对原貌时，用源 PDF 渲染对应页原图交付（也用于复核文字层噪声）：

```bash
python scripts/search_atlas.py --render "22G101-1:88" --out-dir ./atlas_out
python scripts/search_atlas.py --render "22G101-3:50-52" --out-dir ./atlas_out
```

**23G101-11（双层 PDF，同样走 txt 快查）**

该图集为「扫描图像 + 隐藏文字层」，文字层可直接检索，与其他分册同样用 `search_atlas.py` 关键词快查：

```bash
python scripts/search_atlas.py --keywords "滑动支座" "抗震构造措施" --atlas 23G101-11
```

注意：其隐藏文字层由识别生成，噪声较大（如「锚固」→「锚因」、竖排侧栏串行），命中后务必 `--render` 目标页原图核对原文。涉及构造图/表格时直接看原图：

```bash
python scripts/search_atlas.py --render "23G101-11:137" --out-dir ./atlas_out
```

文字层噪声导致页码提取不可靠时，用 `--map` 换算兜底：

```bash
python scripts/search_atlas.py --map 23G101-11:7-1   # 内部页码 → PDF 页码
python scripts/search_atlas.py --map 23G101-11       # 列出全部章节首页映射
```

**23G101-11 章节首页映射（内部页码 → PDF 页码）**

| 章节 | 内容 | 内部首页 → PDF 页 |
|------|------|------|
| 1 | 一般构造 | 1-1 → 13 |
| 2 | 柱和节点构造 | 2-1 → 36 |
| 3 | 剪力墙构造 | 3-1 → 55 |
| 4 | 梁构造 | 4-1 → 71 |
| 5 | 板构造 | 5-1 → 97 |
| 6 | 基础构造 | 6-1 → 106 |
| 7 | 楼梯构造 | 7-1 → 137 |
| 8 | 附录 | 8-1 → 139 |

换算规则：内部页「C-P」对应 PDF 页码 = 上表 C 章首页 PDF 页码 +（P − 1）。例如 6-7 → 106 + 6 = PDF 112。

**用户规范（references/specs/<编号>.txt，同样走 txt 快查）**

```bash
# 只检索规范
python scripts/search_atlas.py --keywords "电渣压力焊" --spec JGJ18-2012

# 检索规范 + 指定图集
python scripts/search_atlas.py --keywords "焊接" --atlas 23G101-11 --spec JGJ18-2012

# 查看规范清单
python scripts/search_atlas.py --list-spec
```

规范命中返回「条文编号」（如 4.1.2），需核对原文时用 `--render "规范编号:页码"` 渲染目标页原图；规范为扫描版（无文字层）时直接渲染定位。

### 第 3 步：按需渲染原图

文字版图集命中页多为「制图规则」文字页；凡涉及构造详图、数值表格，或需核对原貌，一律用 `--render` 把目标 PDF 页渲染成高清 PNG，配合文字一起交付（原图忠实于图集，是「以原文、不修改、不删除」的最直接体现）。命令格式见第 2 步各来源小节：`--render "图集号:页码"` 或 `--render "规范编号:页码"`。

### 第 4 步：汇总输出

按下述「输出规范」组织回答：原文引用 → 内容摘要 → 来源引用 → 总结。

## 输出规范

### 原文（不改写、不删减）

- 从脚本返回的原文片段或渲染页中，**逐字引用**与问题直接相关的原条文（图集条文或规程条文），放入引用块；不得改写措辞、不得删减关键限定条件。
- 保留原条文中的数值、符号与单位（如 laE、d、φ、@、加密区范围等）。
- 文字层含图面噪声（竖向栏、乱码、符号误识）时：正文可读部分按原文引用；明显噪声不引用，并注明「文字层存在识别噪声，以原页为准」。
- 原文较长时只引用相关条款，不引用整页无关内容。

### 数值表格（必须完整呈现）

- **完整表格规则**：回答涉及数值表（图集的 la/laE 锚固长度表、ll/llE 搭接长度表、保护层表、楼梯类型表、箍筋加密区表，或规程中的焊接工艺参数表、接头尺寸表等）时，必须以**渲染原图为数据源，将表格的【全部行 × 全部列】完整转录**：
  - 全部钢筋种类行（HPB300、HRB400/HRBF400/RRB400、HRB500/HRBF500 等，一项不落）；
  - 全部抗震等级档（一、二级 / 三级等）；
  - 全部混凝土强度等级列（C25~≥C60）与直径档（d≤25 / d>25）。
- **禁止只摘局部**：不得只列一个钢筋种类或几个强度等级作为"示例"而省略其余；表格过大时可分多段完整列出，并说明表内单位（如 ×d）。
- 表格数据取自渲染原图视觉读取；文字层噪声以原图为准，必要时逐格核对。

### 内容摘要

- 在原文之后，用「要点」分条归纳，做到条理清晰、表述合理：先讲结论性构造要求，再讲数值、适用条件与例外。
- 每条摘要须能在原文中找到对应依据，并在行尾标注页码（如「——22G101-1 第2-8页」）。
- 摘要中不得出现原文没有的构造要求或数值；确需补充一般工程常识时，须单独注明「（补充说明，非图集原文）」。

### 来源引用

统一格式：**来源名称 + 页码 + 条文号/图号（如有）**。

- 图集：**图集号 + 页码 + 图号**，页码优先用图集内部页码（如 22G101-1 第2-8页）；内部页码不可得时用「PDF 第 X 页」并注明。构造图以「图 X.X.X-X」号引用（如 图4.2.4-4）。
- 规范：**规范名（编号）+ 条文号 + PDF 页码**，如「钢筋焊接及验收规程 JGJ18-2012 第 4.1.2 条（PDF 第 19 页）」。

### 总结

- 位置：来源引用之后，作为回答的收尾。
- 内容：用 1~3 句话归纳本次查询的核心结论，突出关键构造要求、数值与适用条件，便于快速取用；查询结果为多条并列时，可分条列出核心数值。
- 约束：总结内容必须来自本次已引用的原文，不得引入原文未覆盖的新要求、新数值或新判断；不重复来源引用的编号格式，不展开论证。

## 表述规则

1. **术语规范**：使用图集与工程规范术语（如「纵向受力钢筋」「箍筋加密区」「绑扎搭接」「机械连接」「电渣压力焊」），不用口语化表述。
2. **逻辑条理**：按「构造位置 → 构造要求 → 数值/条件 → 例外/注意」的顺序组织要点。
3. **区分来源**：明确标注「图集原文」「规程原文」「摘要（依据来源）」「补充说明（非原文）」四类内容，避免混淆；规范与图集条文冲突时并列给出、注明来源。
4. **不确定处理**：检索无命中或页面不清晰时，如实说明，改用同义词、规范/图集内部术语重试，或查看目录页定位；不得编造条文。

## 注意事项

- 本技能以 `atlas/` 下 4 本图集 + `specs/` 下用户规范为查询范围，不引用其他版本（如 16G101）条文。
- 规范为**用户自行上传**的规范/规程，仅用于当前查询会话及本技能知识库；引用时以原文件为准，不替代正式出版物。
- 22G101 系列替代 16G101 系列，回答时如涉及新旧差异以本图集为准。
- 图集与规程均为官方出版物，本技能用于查询、学习与工程引用，不用于商业传播。

## 资源说明

- `atlas/`：4 本图集 PDF（22G101-1、22G101-2、22G101-3、23G101-11），用于渲染原图。
- `specs/`：用户上传的规范/规程 PDF + `manifest.json` 登记表（规范编号、标题、原文件名、页数、类型、导入日期）。
- `references/`：4 本图集的全文索引 `22G101-1.txt`、`22G101-2.txt`、`22G101-3.txt`、`23G101-11.txt`（每页以 `--- PDF页N ---` 分隔），关键词快查用。
- `references/specs/`：规范全文索引 `JGJ18-2012.txt` 等（与图集索引同格式）。
- `scripts/search_atlas.py`：图集与规范检索脚本（依赖 pymupdf；默认走 txt 快查，缺失自动回退 PDF 扫描；支持检索、--map 页码换算、--render 渲染目录页/任意页/规范页、--list-spec 规范清单）。
- `scripts/import_attachment.py`：导入用户上传的规范/规程 PDF 为规范（复制原件 + 建索引 + 登记 manifest，一次性维护用）。
- `scripts/extract_kb.py`：从 atlas/ 源 PDF 重建 references/*.txt（一次性维护用）。
