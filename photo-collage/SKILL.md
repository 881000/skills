# 实景拼贴

把一张用户提供的照片变成安静、有触感的纸刊海报。保留核心法则：**真景为锚、插画成场、色彩成结构、撕纸成界、纸面会呼吸**：

- 让照片场景保持真实；
- 用更大的抽象插画场重新诠释选定的源图元素，而不是描摹它们；
- 把树叶、枝条、人群、肌理与其他复杂细节压缩成少数安静的图形形式；
- 让加入的色相与插画共享源图导出的形状，而不是漂浮成装饰；
- 在摄影变成纸面的地方保留可见的手撕纤维边缘；
- 让省略与负空间成为插画的主动部分。

默认返回生成的图片与一句简短的创作思路。仅当用户明确要求时，才给出最终 prompt 或详细构图说明。

## 决策优先级

冲突时按此顺序裁决：

1. 保留场景身份与关键空间关系。
2. 让摄影部分保持真实。
3. 把复杂的有机或重复细节简化成少数大而清晰的团块与方向性手势。
4. 让插画成为大的、经过设计的场，而不是照抄或边缘小回声。
5. 让摄影、插画与一个加入色相建立在同一条源图导出的构图骨架上。
6. 让加入的色相成为改变平衡、运动、图底或意义的色彩结构。
7. 在放大插画的内部与周围保留大量安静空间。
8. 在主要材料交接处保留触感的手撕照片边缘。
9. 添加一个克制的、源图感知的微文字元素，不削弱画面层级。

先保关系，再删细节；先删细节，再加装饰。

## 授权与隐私

- 用户提供参考照片并请求制作、转化或继续海报，即视为授权使用图像生成；**不要再次询问**。
- 只把最终 prompt 与必需的参考图交给生图工具。
- 不浏览、不搜索、不保存、不提交、不分享、不把用户的源材料上传到别处。
- 不引入无关的个人信息。仅在不会破坏所请求构图的前提下一般化可识别细节。
- 除非用户要求，否则不把源图或生成图保存进工程文件。

## 先读照片

建立内部**场景卡（Scene Card）**：

- **核心主体**：让场景可辨认的一到两个元素。
- **支撑元素**：交代地点或氛围的二到三个元素。
- **空间不变量**：必须存续的地平线、相对位置、尺度、透视、朝向、路径、剪影或交叠。
- **主导手势**：最强的水平、垂直、对角、曲线、汇聚、注视或运动。
- **视觉重量图**：由面积、明度、饱和度、肌理、人脸、孤立感与边缘张力形成的重量。
- **原生色彩氛围**：主导色相族、冷暖、明度区间、已存在的饱和区域。
- **源形候选**：一到两个可以同时成为插画与色彩结构的剪影、平面、阴影、路径、建筑节奏或氛围形。
- **自然安静区**：天空、水面、墙面、地面、雾气或低信息区域。
- **语义最小集**：仍能辨认出这一具体场景的最小形与关系组合。

把照片当作事实来源，把插画当作对该事实的诠释。

## 照片特定 Prompt 编译器

按顺序解决这些可见字段：

1. **画布**：比例、纸面、扁平扫描、无样机框。
2. **注意力几何**：主导场、从属场、焦点区、安静区、视线路径。
3. **场景不变量**：必须保持可辨认的精确关系。
4. **照片–插画分配**：哪些保持摄影、哪些变成纸上插画。
5. **源形提取**：哪一两个可见形状可以贯穿摄影、插画与色彩。
6. **抽象图**：保留什么、合并什么、省略什么、转化什么、留白什么。
7. **插画场**：主语法、场范围、活跃印刷密度、复杂度压缩目标、支撑痕迹、内部负空间占比。
8. **色彩结构**：精确色相、源图形状、整合模式、材料、不透明度、视觉功能、近似面积。
9. **撕纸交接**：可见手撕轮廓、纤维边缘、露出的纸色调、受影响周长、任何明显从属的残留。
10. **印刷质感**：纸纤维、颗粒、油墨行为、扫描噪声、平光。
11. **微文字系统**：精确的提供或自撰措辞、语言模式、层级、位置、尺度、墨色、与纸面融合的字体处理。
12. **情绪与硬规避**：情绪温度与禁用美学。

只编译能变成可见像素的指令。不要把设计理论解释、文件路径、元数据或分析笔记写进最终生成 prompt。

## 最小抽象引擎

### 默认抽象程度

默认使用**中等抽象**：

- 保留核心主体、主导手势与一条关键空间关系；
- 去掉大约 60–80% 的小描述性细节；
- 把重复或相邻的形合并成更大团块；
- 用平涂墨、断线、稀疏排线、半调或剪纸替代写实阴影；
- 当场景仍可辨认时，允许插画偏离字面尺度或裁切；
- 至少保留一个毋庸置疑的源图特征。

只有当人脸、物件、建筑或地点否则将不可辨认时，才使用更低抽象。仅当用户明确要求、或场景的语义最小集仍然清晰时，才使用更高抽象。

### 建立抽象图

对每一段插画区域决定：

- **保留**：至多保留一到两个定义性形或关系。
- **合并**：把重复的树、栏杆、窗、浪、人群或建筑细节合成一个节奏或剪影。
- **省略**：移除次要物件、表面细节、杂乱与冗余轮廓。
- **转化**：把选定形变成平涂剪影、断线、几何剪纸、墨场或重复痕迹。
- **显露**：在形内与形外刻意留纸空白。

不要复刻照片里每个可见物件。不要做一张盖了复古肌理的逐场景描摹。

### 选择一种主插画语法

按源图选择一种语法：

- **剪影主导（Silhouette-led）**：一个大暗或灰团块承载主体；用于人物、树、屋顶、船或强侧影。
- **轮廓主导（Contour-led）**：几条断线保留方向与关系；用于建筑、路径、栏杆、岸线或手势。
- **场主导（Field-led）**：一个不规则墨场或半调场暗示氛围；用于水、雾、天空、阴影或地面。
- **节奏主导（Rhythm-led）**：重复痕迹压缩重复元素；用于柱、窗、浪、枝、阶或人群。
- **剪纸主导（Cut-paper-led）**：一到两个简化有机或几何剪纸承载场景；用于源图有强形状层级时。

只使用一种主语法，至多一种辅助语法。不要在一幅插画里混用所有印刷工艺。

### 压缩密集树叶与有机细节

当源图变得视觉繁复时提高简化程度。密集的树、松针、叶、藤、草、花、毛发状枝条、人群、砾石与类似微肌理，在插画里必须比在摄影里更安静。

- 对树叶主导的插画区域：保留一个主树冠或树团块、一到三个方向性枝手势、至多两个次级簇、一个稀疏肌理样本。
- 省略大约 85–95% 的个别叶、针、细枝、交叠小枝与重复有机痕迹。
- 对树与树叶默认使用剪影主导或剪纸主导语法。节奏主导痕迹只作稀疏支撑，绝不作为细节的底层地毯。
- 把叶或针表现为成组团块、断裂叶裂片、剪下的阴影形或短促中断的节奏；不要逐片绘制。
- 保留源图特有的倾斜、树冠开口、枝向或光隙，而不是保留植物学细节。
- 若源图含多棵交叠的树或灌木，合并成一个主导团块加至多一个从属反团块。
- 若缩略图尺寸下插画读作蕾丝、花丝、珊瑚、密集版画或整幅植物印刷，就合并形式并移除痕迹，而不仅仅是淡化。

照片里的复杂度是「要简化更多」的理由，不是「要印更多」的理由。

### 控制插画密度

- 区分**场范围**与**印刷密度**。让插画影响海报大约 45–70%，同时让该场的很大一部分明显未印刷。
- 让插画场的 55–75% 保持安静；对简单场景允许 65–85%。
- 对树叶主导或高度繁复场景，让插画场的 65–85% 安静，活跃插画约占整幅海报 10–25%。
- 当场较大时，让活跃插画墨、剪纸或半调约占整幅海报 15–35%。
- 使用一个足以影响整体剪影的主导插画团块，加一到两个支撑痕迹、一个克制的肌理场。
- 除纸色调与单一加入色相外，中性墨值至多两种。
- 偏好未完成边缘、中断轮廓、裁切形与内部负空间，胜过完全闭合的精细物件。
- 让留白纸面分隔视觉概念。允许的边缘斑点或幽灵痕迹只限于照片–插画过渡处；不要把散落当成填充安静场的填絮。

先放大插画，再增加细节。对密集有机场景，放大团块并减少痕迹数量。结果应在缩略图尺寸清晰可读，在正常尺寸仍感觉有意未完成。

## 抽象中的场景保真

通过以下方式保留场景身份：

- 核心主体的相对位置与方向；
- 主导地平线、路径、岸线、注视或剪影；
- 一到两个源图特有的形状；
- 重与静区域之间原有的视觉张力。

插画可以简化解剖、肌理、尺度与轻微透视。它不得虚构无关场景，或用通用母题替换原有空间逻辑。

## 构图系统

### 艺术理论基础

- **图底**：让正形在安静纸面上可辨。
- **视觉平衡**：平衡视觉重量而非等面积。
- **强调**：通过可控对比建立一个主焦点区。
- **运动**：用源图线条、边缘、注视、路径与色彩序列引导视线。
- **主从层级**：除非源图有意对称，否则避免偶然的五五分。
- **网格作脚手架**：仅当三分布局、中轴或黄金分割点强化源图几何时才使用。
- **有方向的呼吸空间**：在注视、路径、浪或对角线前方留出空间。

### 弹性布局区间

- **转化接缝**：摄影约占 30–50%；让一个真实主体、地平线、路径、阴影或剪影跨过边界，延续成更大的插画场。
- **底色叠印**：摄影约占 35–60%；让一个宽广低密度的插画与彩色底色在摄影后方及部分穿过摄影延伸，不损伤定义性细节。
- **照片锚点 + 扩展场**：摄影约占 25–45%，插画场约占 45–70%；把事实场景放在一个强锚点，让抽象承载更宽的构图。
- **方向切分**：从约 55/45 到 65/35 起步，但让切分对齐真实地平线、注视、路径、结构边缘或汇聚，并让插画有选择地穿过切分。
- **不规则碎片**：照片碎片合计约占 25–50%；把核心主体放在最大碎片里，用一个共享插画团块或色彩结构连接各碎片。

避免反复默认「居中照片 + 下方文字」的布局。按源图的主导手势与视觉重量图选择布局。把这些当作起始区间，再按真实视觉重量修正；绝不为凑数字牺牲场景身份或插画清晰度。

## 照片–插画边缘过渡

把边界当作真实的纸对象。在主要摄影锚点与米白纸面或抽象插画相遇处，默认使用**可见的手撕纤维边缘作为主过渡**。直接转化、斑点或幽灵痕迹可以支撑交接，但不得取代有触感的撕纸。

用手撕边缘构造：

- 不规则手撕轮廓，带浅凹口、不均匀起伏、柔和的扇形与偶尔更长的纤维拉出；
- 一条窄的羽毛状纤维边缘，露出的纸纤维与暖纸色调打断摄影边缘；
- 选定边缘段的轻微局部变薄、磨损、断裂乳剂或干颜料剥落；
- 自然不对称：有些段近乎笔直，有些轻微破烂，有一两处更强的撕纸压力点；
- 扁平扫描行为，无人工抬纸深度。

控制过渡：

- 让活跃纤维带保持窄，约为海报短边的 1–4%。
- 让撕纸轮廓沿主照片–纸交接处明显可辨，约覆盖可见摄影周长的 35–70%；既避免完全均匀的边框，也避免几乎看不见的边缘。
- 让插画或色彩结构跨过、从中浮现或在选定撕纸段后方穿过，同时让纸撕本身保持可读。
- 只在靠近一两个构图压力点处，使用点状消解、半调碎屑或一到三个微弱的幽灵痕迹作为从属残留。
- 保持圆点尺度与间距不规则。保持符号残缺、微弱、非言语、来自印刷。
- 使用纸色调、石墨、炭黑、褪色棕黑或现有的单一彩色相；不引入第二色相。
- 保留周围安静场。缩略图尺寸下，撕纸边缘应清晰建立材料分离，而不成为装饰框或第二个焦点簇。

避免干净的数码剪贴路径、利落的矩形遮罩、统一白描边、贴纸边框、装饰性毛边框、沉重投影、卷角、厚叠纸深度，以及每边均匀施加的撕纸效果。

## 色彩结构引擎

把**一个加入的印刷色相**用作构图的一部分，而不是最终的装饰痕迹。摄影部分的自然色不算额外加入色相。

### 选色相

识别照片的主导色相族、冷暖、明度、饱和度与有意义的次要色。再按关系选择加入色相：

- **安静和谐**：使用更饱和的类似色相。
- **聚焦对位**：使用补色或近补色。
- **温度桥**：在冷场景放暖色，或在暖场景放冷色。
- **源图共鸣**：强化有意义的次要源色。

指定精确颜色，如高饱和钴蓝、不透明群青、干净番茄红、鲜明梨绿、柠檬黄或饱和洋红粉。把它放在源色、纸色调与中性墨色旁边判断，而不是孤立判断。不要用 `pale`、`muted`、`faded`、`pastel` 或 `low-saturation` 措辞削弱色相，除非用户明确要求。

### 选择一种整合模式

- **源图延续**：提取屋脊线、道路、云、窗、衣物、阴影、植物、车面板或其他源图特有形式，并把它延续出摄影边缘。
- **选择性替换**：把一个真实摄影区域转成平涂高纯度印刷形状，同时保留周围场景。
- **底色通道**：把一个宽广的半透明、半调或错位色场放在摄影与插画之后、部分穿过两者。
- **反形**：从源图剪影、缝隙、阴影或安静区导出一个彩色正形或负形。
- **方向节奏**：沿注视、路径、栏杆、山脊、岸线或汇聚重复或拉伸一个源图导出的彩色形。

选择一种整合模式与一个主要功能：焦点强化、平衡砝码、照片–插画桥、视线路径方向、图底澄清或语义强调。

要求色彩结构至少满足以下两项测试：

- 其轮廓、位置或节奏源自所提供的场景；
- 接触、交叠、替换、位于其后或穿过摄影或插画；
- 跨过照片–纸边界或在边界处转化；
- 改变视线路径或重新平衡视觉重量；
- 揭示或强化真实主体、空间关系、氛围或情绪张力。

绝不要仅仅为了让海报显得有设计感而使用脱离的矩形、角落补丁、通用圆、任意亮斑或孤立笔刷色块。仅当简单几何形明确源自或附着于源图几何时才允许。可选用一到两个更小的源图锚定回声重复该色相；保持它们从属。

### 面积与材料匹配

- **不透明替换或剪纸形**：通常约占整幅海报 2–6%。
- **半透明、半调或错位底色**：通常约占 6–15%。
- **大的结构性色彩场**：通常约占 10–20%；使用此区间时降低不透明度、中性墨密度与竞争细节。
- 照片已含鲜艳色时用下限；源图素净且加入色相承担必要结构角色时用上限。
- 通过颗粒、墨渗、断裂覆盖与轻微错位保持高纯度，而不让色相变成霓虹或光泽数码色。

### 结构移除测试

在脑中移除加入色相。如果视线路径、视觉平衡、图底关系、照片–插画连续性与场景诠释基本不变，就重新设计。色彩必须承担构图工作。

## 视觉语言

- 默认使用竖版 3:5 纸海报画布，除非用户要求其他比例。
- 使用暖米白做旧纸面，带哑光纤维、克制的斑点、风化、撕边、扫描噪声与平印质感。
- 保留照片的自然色彩氛围与可辨认几何。
- 用选择性木刻、影印、半调、静电复印、Risograph、活版或剪纸处理渲染插画。
- 让摄影、插画与色彩结构共享至少一条源图导出的轮廓、轴、节奏或场。
- 让纸肌理从属于抽象形与负空间。
- 保持结果扁平、正交、漫射光、无人工 3D 深度。
- 只添加下面定义的那一个微文字元素；它是安静的编辑痕迹，绝不是标题。

## 微文字系统

文字是此版本海报语言的常规而微妙的组成部分。它应感觉像在纸上被发现，而不是设计在图像上方。

### 选措辞

- 若用户提供了文字，**原样复现**；不翻译、不扩写、不改写、不加副标题、不加署名。
- 否则，从提供的场景自撰一行紧凑文字：或一个具体的场景相关短语，或一个非常短、广泛共鸣的诗意思考。不虚构署名引文，不把它归于任何人。
- 支持三种语言模式：**纯中文**、**纯英文**、或**中英成对**。
- 默认使用**纯英文**。仅当用户明确提供该措辞或要求该语言模式时，才切到纯中文或中英成对。
- 中文必须**不超过 8 个汉字**。英文必须**不超过 5 个单词**。中英成对时两条限制独立适用，并让两行语义相连。
- 英文可取三种形式之一：**一个独立单词**、**关键词序列**、或**一个极短短语**。不要求完整句子。
- 偏好克制、有唤起力的语言，而非解释、广告、日期、地名、标签、解说或完整叙事句。
- 让文字回应一个真实视觉线索：场景里的天气、物件、季节、时间、运动、光、距离、触感或沉默。

### 无文字提供时的默认方向

选择**一种观察到的感受，而非元数据**。除非用户另有说明，否则写一行英文，命名场景安静的余韵，而不是记录何时何地发生。

按此选择顺序：

1. **独立场景词**：图像有强单一主体或情绪时用一个具体或氛围词。示例：`Horizon`、`Rain`、`Stillness`、`Drift`、`Shelter`。
2. **关键词序列**：选两到四个可见或氛围词，用一个重复分隔系统连接。示例：`Cloud / Ridge / Silence`、`Glass · Light · Summer`、`Rain, Window & Night`。
3. **极短短语**：当运动或情绪方向比命名更重要时，用一句紧凑的与图像相关的短语。示例：`After the rain`、`Falling light`、`Almost home`。

- 对日常、记录式、物件主导或地点主导的照片用具体场景语言。对孤身人物、黄昏、雨、旅途、等待、距离或明显沉思的场景用情绪碎片。
- 对关键词序列，偏好来自可见主体、材料、天气、地点氛围、运动或光的名词与克制形容词。总计不超过五个英文单词。
- 只选一种分隔样式：逗号、居中圆点 `·`、斜杠 `/` 或与号 `&`。当自然的编辑节奏有帮助时用逗号加末尾与号。不要在一行里混用几种装饰分隔样式。
- 把标点当作间距与节奏，而非装饰。在 `·`、`/`、`&` 周围留宽；逗号紧贴前词。
- 不要因场景的情绪、地点或主体而放弃英文。语言模式跟随用户指令；视觉性格影响措辞与字体，不影响默认语言。
- 当用户要求中英成对时，让一种语言成为安静的主动行，另一种成为更小的回声。不要让两行都是同级标题。两行可以是近义翻译或互补碎片，但必须描述同一种视觉感受。
- 默认不使用日期、时间、地址、坐标、天气读数、档案戳或序列号。仅当用户明确要求、或源图本身让这类记录式信息成为本质主体时才使用。
- 不要强塞名句。一句属于这张图像的小原创短语，通常比从别处借来的可辨认句子更有说服力。

### 字体与材料

- 让文字小：中文约占海报高度的 1.5–3.5%，英文约 1.3–2.8%；必须明显从属于照片与插画。
- 渲染成轻度不完美的手写、打字机式活版、淡铅笔、磨损印章或干墨——选一种适合场景的处理。绝不使用抛光数码展示字体。
- 对英文，偏好小的复古打字机衬线或等宽机械字体，适度字宽、略不平的基线、不规则油墨压力与克制的字距。使用句首大写、小写或安静的首字母大写；避免粗体全大写展示字。
- 对独立单词或关键词序列，稍更坚实的暖黑、深炭或深棕黑打字机压痕可接受，与参考的紧凑编辑行一致。让字母足够小，使较深油墨不成为标题。
- 中英成对时，让中文用淡手写、铅笔或克制的宋体印刷，英文用更小的打字机/活版处理。共享一种对齐与墨色家族，使成对读作一个纸对象。
- 把字母融进纸面：略不均匀的压力、断裂油墨、微妙吸墨、柔和边缘磨损，以及与海报相同的平扫肌理。
- 使用安静的纸源墨值：炭黑、暖灰、褪色棕黑、哑石墨，或现有色相一个非常克制的回声。保持足够对比在正常尺寸可读，但绝不用明亮新色。
- 字体可以适度不规则，但确切字符/单词必须可读且拼写正确。

### 位置与层级

- 把文字放在放大的插画下方、旁边、偏移处或安静口袋的现有留白纸面——不放人脸、定义性主体或密集印刷区。
- 对齐到源图边缘、撕纸照片边缘、主导轴或视觉基线；四周留足呼吸空间。
- 纯中文或纯英文默认单行。中英成对用两行紧密相关的短行，主次层级清晰。
- 把文字当作视线路径的最终休息点，而不是入口或焦点中心。让其视觉重量低于色彩结构，远低于核心主体。
- 不要为了支撑文字而添加装饰线、图标、标签、序列号、地址、时间戳或伪编辑元数据。

## Prompt 形状

把最终 prompt 写成四个紧凑段落：

1. **画布与注意力几何**：比例、布局、照片/插画占比、焦点区、安静场、视线路径、预留文字区。
2. **场景保真**：核心主体、空间不变量、哪些保持摄影。
3. **插画场、色彩结构、撕纸边与微文字**：保留/合并/省略/转化/显露决策；插画语法、复杂度压缩目标、场范围、活跃密度；色彩整合模式、源图形状、精确色相、材料、不透明度、功能与面积；可见手撕轮廓、纤维带、受影响周长与从属残留；确切文字、语言模式、形式、分隔符、层级、字体、墨值、尺度与位置。
4. **印刷情绪与约束**：纸/扫描肌理、情绪氛围、文字可读性、硬规避。

用决断性语言。说清哪些细节必须消失，同说清哪些形必须留下一样重要。

## 生成工作流（豆包环境）

1. 检查用户提供的照片；若源图是本地文件路径，先把它上传为图片 URL，供生图工具引用（本地资源必须先转成 URL 才能作为参考图）。
2. 建立场景卡，识别语义最小集。
3. 选焦点区与预期视线路径。
4. 提取一到两个能共同组织摄影、插画与色彩的源图形状。
5. 选源图驱动的构图，设初始照片/插画场区间，再按视觉重量修正。
6. 建立抽象图。
7. 选一种主插画语法；需要时应用树叶与微细节压缩，先放大场再增加细节，然后设定活跃密度与留白占比。
8. 选一种色彩整合模式、精确色相、源图形状、材料、不透明度、功能与面积；应用结构移除测试。
9. 在主照片–纸交接处建立可见手撕纤维边；先设轮廓、纤维带、受影响周长，之后才加任何从属斑点或幽灵痕迹。
10. 解决语言模式、文字形式、确切微文字、分隔系统、层级与留白位置；有提供的措辞就逐字使用，否则默认纯英文。
11. 编译四段最终 prompt。
12. **调用生图工具**：使用 `image_edit`，把源图 URL 放入参考图列表，把编译后的 prompt 作为编辑/生成指令，按目标比例设置宽高（默认 3:5 竖版约为 1229×2048；用户要求其他比例时相应换算），并优先选择可用的最高质量模型版本。prompt 聚焦「海报必须如何构成：哪些保持真实照片、哪些转为插画与色彩结构」，而不是复述源图已有特征。
    - 若参考图不可用或工具要求必须先上传，先完成上传得到 URL 再调用。
    - 若 `image_edit` 不可用，改用 `image_gen`，此时 prompt 需自带足够的源图语义描述。
13. 在正常与缩略图两种尺度检查结果。
14. 如必要，**定向重跑至多一次**，只修正观察到的失败项（见下节）。
15. 返回生成的图片与一句简短创作思路；仅当用户要求时，才给出 prompt 或详细说明。

## 定向修正

至多重跑一次，只修正观察到的失败项：

- **场景丢失**：恢复缺失的空间不变量或源图特有形式。
- **插画过实**：移除至少一半剩余细节，合并形式、断开轮廓、放大留白。
- **密集树叶**：把个别叶、针与细枝塌缩成一个主团块、一到三个枝手势、至多两个次级簇。
- **通用抽象**：用简化的源图导出形式或关系替换虚构母题。
- **拥挤**：把插画减到一个主团块、一个支撑痕迹、一个肌理场。
- **插画太弱**：放大场或主导团块，不增加描述性细节。
- **层级弱**：放大主导场或简化从属场。
- **缺失纸边界**：在主交接处恢复可见的不规则手撕轮廓、窄露纤维边与暖纸色调打断。
- **边缘噪声**：让撕纸纤维保持主位，减少其他一切残留，把斑点或幽灵痕迹限制在一两处压力点，恢复留白纸面。
- **装饰性色彩**：用源图延续、替换、底色、反形或方向节奏替换脱离的痕迹；让它通过结构移除测试。
- **色彩主导**：在保留色彩构图功能的同时减小面积、不透明度或竞争回声。
- **文字失败**：恢复确切措辞、缩小或降低其对比、移进留白纸区、或让字体更融于纸面。
- **摄影受损**：恢复自然色、肌理、透视与可辨认细节。

## 硬性规避

避免：字面描摹插画、逐叶逐针渲染、密集枝蔓花丝、蕾丝状植物插画、覆盖整场的重复有机痕迹、怯生生的边缘插画、整幅影印、均匀精细的木刻渲染、处处密集排线、完整物件描边、填充装饰、通用抽象母题、脱离的角落色块、孤立笔刷色块、任意亮斑、与源图无关的通用几何强调、构图定稿后才加的颜色、干净数码照片遮罩、利落矩形裁剪、贴纸式白描边、装饰性均匀毛边框、沉重纸影、卷角、密集剪贴簿、均匀点状边框、重复装饰图标、可读的伪符号系统、多种互相竞争的插画风格、多个加入色相、商业广告层级、logo、CTA、光泽样机、霓虹、3D、电影打光、景深、时尚编辑式戏剧、可爱卡通或动漫处理、过度锐化、AI 平滑、大或抛光数码字体、粗体全大写展示字、关键词堆砌、混用装饰分隔符、不可读或拼写错误的文字、长文字块、虚构引文或署名、伪元数据与任何水印。

## 输出格式

默认返回：

```markdown
**生成图**

![实景拼贴纸刊海报](图片文件/URL)

**创作思路**

[一句到三句紧凑中文，解释源图导出的构图、放大的插画场与加入色相的结构角色。用平实的语言描述中心视觉决策与情绪意图；不暴露完整 prompt，不重述每个参数，不变成技术清单。]
```

- 把生成的图片通过图片交付工具（present_files）交付给用户，并在交付时写明产物路径。
- 若用户明确要求 prompt 或详细说明，只补充被要求的项。构图说明可使用：

  - 布局：构图与近似照片/插画场占比
  - 视线路径：入口 → 摄影锚点 → 色彩/插画通道 → 安静出口
  - 抽象：保留 / 合并 / 省略 / 转化 / 场范围 / 活跃密度 / 留白占比
  - 色彩结构：源图形状 / 整合模式 / 精确色相 / 材料 / 不透明度 / 功能 / 近似面积
  - 边缘：撕纸轮廓 / 纤维带 / 受影响周长 / 穿越形 / 从属残留
  - 文字：确切措辞 / 语言模式 / 文字形式 / 分隔符 / 字体 / 墨值 / 位置 / 尺度

- 不暴露生图 prompt，除非用户明确要求。
- 不要把本技能的方法细节作为用户可见内容输出。

## 质量门

返回前逐项核验：

- 结果是否仍读作所提供的场景？
- 语义最小集与关键空间关系是否可辨认？
- 摄影部分是否真实？
- 插画是否在诠释而非描摹源图？
- 是否已移除大部分非必要细节？
- 是否只有一种主插画语法？
- 插画是否影响海报的实质部分，而不是像怯生生的边缘涂鸦？
- 插画是靠尺度和场范围放大，而不是靠增加细节？
- 树叶主导场景中，大部分叶、针、细枝与重复有机痕迹是否已合并或省略？
- 树叶是否化解为少数大团块与方向性枝手势，而非密集花丝？
- 插画内部与周围是否有大量负空间？
- 留白纸面是否澄清形式，而不是显得碰巧空白？
- 摄影、插画与色彩是否共享一条源图导出的轮廓、轴、节奏或场？
- 主照片–纸交接处是否有可见手撕纤维边？
- 撕纸边是否显示不规则轮廓、窄露纤维、暖纸色调与自然变化，且不成为均匀边框？
- 直接转化、斑点与幽灵痕迹是否从属于撕纸边界？
- 斑点与幽灵痕迹是否限于有意义的压力点、缩略图尺寸微弱、无可见图标？
- 边界是否无干净数码裁剪、贴纸描边、沉重阴影与人工卷纸深度？
- 视线路径是否连贯？
- 色彩相、源图形状、整合模式与位置是否有据可依？
- 是否只有一个加入色相？
- 色彩结构是否满足至少两项整合测试？
- 移除该色相是否会削弱平衡、运动、图底、连续性或意义？
- 色彩是否结构上有用，而不在缩略图尺寸下成为脱离贴纸或主导广告装置？
- 微文字是否逐字使用提供措辞，或自撰时符合中文/英文长度限制？
- 文字是否默认纯英文，仅当用户提供或要求时用纯中文或双语？
- 若自撰英文，是否为刻意的独立单词、关键词序列或短短语，而非多余句子？
- 若用关键词序列，是否含两到四个场景相关词且用一种一致分隔系统？
- 若双语，是否一行明显从属且两行语义相连？
- 文字是否可读、融于纸面、安静且从属于画面？
- 文字是否放在真正留白处，而不成为解说、标题或视觉干扰？
- 海报是否保持触感、扁平、安静、抽象、源图导出且非商业？
- 回复是否包含图片与一句真正简短的创作思路？
- 是否未暴露完整 prompt（除非用户明确要求）？
