# 建筑施工手册

《建筑施工手册（第六版）》是覆盖建筑工程全专业的权威工具书。本技能将其 6646 页全文提取为按章节切分的文本知识库，供精确检索和引用。

## 知识库结构

`references/` 目录下：

- `INDEX.md` —— 全书 41 章的分级目录索引（含各小节对应的 PDF 页号），**检索第一步先读它**。
- `0 封面与前言.txt` —— 出版说明、编委会、编写分工、全书目录页。
- `1 施工项目管理.txt` ~ `41 电梯安装工程.txt` —— 每章一篇全文，文件内以 `--- PDF页N ---` 分隔每页，页首数字为原书页码。

## 检索流程（必读）

回答任何建筑施工问题，按以下顺序：

1. **读索引定位章节**：Read `references/INDEX.md`，用 `Grep` 在 INDEX.md 中按关键词找到相关章节与小节及 PDF 页号。多数问题对应 1~3 个章节；例如"钢筋锚固"→第17章，"防水混凝土抗渗"→第31章，"脚手架连墙件"→第14章。

2. **关键词定位**：优先用脚本检索（推荐），或对具体章节文件用 Grep：
   - `python scripts/kb_search.py <关键词...> [--chapter 章号] [--ctx N] [--limit N]`
   - 多关键词默认要求**同一页同时出现**（AND）；需要模糊匹配加 `--any`。
   - Grep 定位：`Grep pattern="关键词" path="references/17 钢筋工程.txt" -A 3 -B 3 -n`。

3. **读取目标片段**：用 Read 打开对应章节文件，从命中行附近读取完整段落/表格。**不要整章通读**（每章 75~720KB），只读目标区域。

4. **引用出处**：回答时注明「章节号 + 原书页码/表号」，如「见第17章，PDF页2860，表17-15」。若需原文核对图表，可回源 PDF（源文件路径见文末）查看对应页。

## 使用示例

- 「大体积混凝土测温点的布置要求」→ `kb_search.py 测温 大体积 --chapter 18` → 读命中片段作答。
- 「防水混凝土的设计抗渗等级怎么定」→ `kb_search.py 抗渗等级 --chapter 31` → 得表31-27。
- 「盘扣式脚手架搭设高度限值」→ `kb_search.py 盘扣 搭设高度 --chapter 14`。
- 「写一份雨季施工措施交底」→ 用 `kb_search.py 雨季 防护` 及第10章季节性施工定位要点后组织内容。

## 注意事项

- 文本由 PDF 自动提取，个别处可能有噪声：数字/符号间的多余空格、个别字符缺损（如表格符号变成 `＠`）、公式符号残缺。引用数值前尽量结合上下文核对。
- 表格多为文字化排版，行列可能不完整；涉及关键数值时注明出处页码，建议按页码回原 PDF 复核。
- 原书分六册装订，PDF 合并为单文件；`PDF页N` 为合并文件页码（页首数字为原书页码，二者不同）。
- 全书出版信息以 `0 封面与前言.txt` 为准。

## 脚本说明

- `scripts/kb_search.py` —— 知识库关键词检索（唯一日常使用）。
- `scripts/extract_kb.py` / `scripts/build_index.py` —— 从源 PDF 重建知识库与索引（一次性维护用，一般无需执行）。
