# 建筑施工手册

《建筑施工手册（第六版）》是覆盖建筑工程全专业的权威工具书。本技能将其 6646 页全文提取为按章节切分的文本知识库，供精确检索和引用。

## 知识库结构

`references/` 目录下：

- `INDEX.md` —— 全书 41 章的分级目录索引（含各小节对应的 PDF 页号），**检索第一步先读它**。
- `0 封面与前言.txt` —— 出版说明、编委会、编写分工、全书目录页。
- `1 施工项目管理.txt` ~ `41 电梯安装工程.txt` —— 每章一篇全文，文件内以 `--- PDF页N ---` 分隔每页；分隔符后首行多为原书页码（部分页为章节号或表格内容）。

## 检索流程（必读 · 升级版）

回答任何建筑施工问题，按以下顺序执行，**每一步完成后再进入下一步**：

1. **读索引定位章节**
   - 先用 Grep 在 `references/INDEX.md` 中按关键词定位相关章节、小节与 PDF 页号，必要时再 Read 目标区域（索引约 432KB，不要整篇通读）。
   - 多数问题对应 1~3 个章节；例如「钢筋锚固」→第17章，「防水混凝土抗渗」→第31章，「脚手架连墙件」→第14章。
   - 拿不准章节时，用近义词多试（如「防水」「抗渗」「刚性防水」），锁定章节后再进下一步。

2. **脚本关键词检索（首选）**
   - 运行 `python scripts/kb_search.py <关键词...> [--chapter 章号] [--ctx N] [--limit N] [--any]`
   - 参数说明：
     - 多关键词默认按「**同一 PDF 页同时包含全部关键词**」匹配（AND），定位最准；
     - `--chapter 章号`：限定章节（支持章号或章节名片段），缩小范围、提速；
     - `--ctx N`：命中行上下文行数（默认 3），数值/条款类检索建议 `--ctx 5`；
     - `--limit N`：每章最多输出条数（默认 5）；
     - `--any`：多关键词切换为「任一命中即算」，用于同义词/近义表述不确定时兜底。
   - 首次命中即读；无命中时按「换同义词 → 拆短关键词 → 去掉 --chapter 全库搜 → --any 模糊搜」的降级顺序重试，**禁止直接放弃**。
   - 备选：对已定位章节用 Grep，如 `Grep pattern="关键词" path="references/17 钢筋工程.txt" -A 3 -B 3 -n`。

3. **读取目标片段**
   - 用 Read 打开对应章节文件，从命中行附近读取**完整段落/表格**（含表号、条文号、数值及适用条件）。
   - **不要整章通读**（每章 75~720KB），只读目标区域。

4. **关键数据核对**
   - 数值、表格、条文类信息须结合上下文核对，警惕 PDF 提取噪声（数字/符号间多余空格、字符缺损如 `＠`、公式符号残缺）。
   - 命中原文与问题问法不一致时，回第 2 步换关键词重查；**不得用印象或二手摘要代替原文**。

5. **按四段式作答**
   - 检索完成后，严格按下节「作答格式（新四段式）」组织回答，并注明出处。

## 作答格式（新四段式）

所有基于本知识库的回答，一律按以下四段组织，缺一不可：

1. **原文**：直接引用知识库原文关键句/关键段落（保留条文号、表号、数值与适用条件），作为回答的事实依据。原文过长时引用最相关部分，其余以省略号过渡，**不得改写原意**。
2. **摘要**：用自己的话归纳要点，把原文拆成可读的几条（数值、条件、适用范围逐项列出），便于快速理解。
3. **来源**：注明「章节号 + 原书页码 + 表号/条文号 + PDF页号」，如「见第31章，原书页码X，表31-27（PDF页XXXX）」。涉及关键数值时给出可回源核对的页码。
4. **总结**：回到用户问题本身给出结论与可操作建议（适用条件、施工要点、注意事项），并点明仍需按实际工程条件复核或存疑之处。

格式示范（以「防水混凝土抗渗等级」为例，内容仅为骨架）：

- **原文**：「防水混凝土的设计抗渗等级……（见原书表31-27）」
- **摘要**：① 抗渗等级按……确定；② 最小抗渗等级为……；③ 特殊部位尚应……。
- **来源**：第31章，表31-27，PDF页XXXX。
- **总结**：本项目可按……取值，同时须满足最小厚度与裂缝控制要求，具体以实际埋深复核。

## 使用示例

- 「大体积混凝土测温点的布置要求」→ `kb_search.py 测温 大体积 --chapter 18`。
- 「防水混凝土的设计抗渗等级怎么定」→ `kb_search.py 抗渗等级 --chapter 31` → 得表31-27。
- 「盘扣式脚手架搭设高度限值」→ `kb_search.py 盘扣 搭设高度 --chapter 14`。
- 「写一份雨季施工措施交底」→ `kb_search.py 雨期 --chapter 10`（10.2 雨期施工）。

## 注意事项

- 文本由 PDF 自动提取，个别处可能有噪声：数字/符号间的多余空格、个别字符缺损（如表格符号变成 `＠`）、公式符号残缺。引用数值前尽量结合上下文核对。
- 表格多为文字化排版，行列可能不完整；涉及关键数值时注明出处页码，建议按页码回原 PDF 复核。
- 原书分六册装订，PDF 合并为单文件；`PDF页N` 为合并文件页码，分隔符后首行多为原书页码，二者不同。
- 全书出版信息以 `0 封面与前言.txt` 为准。

## 脚本说明

- `scripts/kb_search.py` —— 知识库关键词检索（日常检索首选，用法见「检索流程」）。
- `scripts/extract_kb.py` / `scripts/build_index.py` —— 从源 PDF 重建知识库与索引（一次性维护用，一般无需执行）。
