# 莫兰迪电影海报

把一张用户提供的照片做成源图忠实的电影感摄影海报，让照片、标题与小字作为一个整体构图存在。完全通过排版、层级、负空间、对齐与选择性深度来构建电影海报效果。结果可以唤起戏剧关键艺术感，但不代表任何真实电影制作。

不要模仿任何有名字的电影海报，不要复制受保护的标题字形。从所提供的场景衍生出原创的排版身份。不要添加装饰性几何符号，不要用拼贴母题替代。

## 1. 锁定摄影底版

- 竖版输入默认精确竖版 3:4，除非用户要求其他比例。
- 用从低信息区（天空、道路、墙面或边缘）做最小安全裁切达到 3:4。保留人脸、地标身份、焦点手势、透视、方向轴与有用的负空间。绝不拉伸。
- 非竖版比例保留原比例，除非用户要求新比例。
- 裁切后，把照片当作 `LOCKED SOURCE PHOTO`（锁定源照片）。
- 在显式字形遮罩之外，保留方向、取景、几何、人物、车辆、标识、云、建筑、窗、色彩、曝光、对比、锐度、原生噪声与肌理。
- 不要重新生成、重绘、修复、重打光、修图、调色、模糊、锐化、降噪、做旧，或添加全局纸效果。

## 2. 写电影构图地图

在选词或选字体之前，先识别：

- 主角主体、语义关键、脸与视线、手势，以及主角是否主导画面；
- 观看者应按顺序注意到的前三件事；
- 能承载可读文字的安静场；
- 剪影边缘、地平线、建筑、光束、道路、消失线与其他方向轴；
- 小字必须避开的高细节、高对比或语义重要区域；
- 一个主文字场、一个支撑文字场、一个可选微信息场；
- 主导色、支撑色与强调色（按色相、明度、冷暖、饱和度与面积）。

陈述一句从可见场景推断出的简短电影前提。该前提只用于指导氛围与措辞；绝不虚构新的视觉事件或人物。

## 3. 选一种戏剧布局原型

选最契合构图的原型，而不是硬套固定模板：

1. **底部锚定（Bottom-anchor）**：主角或氛围主导上方；标题与演职员稳定下方场。
2. **顶部宣告（Top-proclamation）**：标题或身份/署名文字占据人像或地标上方的开阔天空或墙面。
3. **中央徽记（Central-emblem）**：标题与主角通过尺度、对齐与选择性深度形成一个标志性中心。
4. **整合轴（Integrated-axis）**：标题跟随或对抗地平线、道路、立面、光束或透视轴。
5. **边缘尺度（Edge-scale）**：标题部分跑出画布以创造电影尺度，同时可读核心保持完整。

不要把文字均匀分布在四边。创造一个主导簇、一个支撑簇、一个安静区。让排版通过尺度、字距、换行、对齐、留白与遮挡承载全部图形节奏。

## 4. 构建自适应电影文案库

使用可见场景事实、用户上下文与原创诗意发明。用户不需要提供真实电影制作信息。未提供时自动写出有品味的文案。

按可用空间选 3–5 个角色；只有标题是必需的：

1. **标题**：一个原创的、从场景衍生的标题，通常 1–4 个词。保持好记、可发音、精确。
2. **身份/署名**：作者名、别名、虚构角色名、虚构创作者署名，或非人称短语如 `A STUDY OF LIGHT AND STONE`。有提供的名字就用；否则发明一个原创的、明显虚构的名字，或省略。
3. **标语**：一句简短的情感主张，通常 3–10 个词，不超过两行。
4. **氛围元信息**：地点、天气、时间、方向、坐标、章节号、档案码或场景名词。
5. **电影微文案**：可选的紧凑页脚，可通过密度与节奏类似演职员表。用场景衍生名词、虚构角色、虚构名字、发明的厂牌或设计研究语言填充。
6. **行动标记**：提供的日期、已知的照片日期、虚构章节/日期码、版次号、`A CINEMATIC STUDY`、`LOCATION PORTRAIT` 或另一个简洁锚点。

当虚构名字、标题、厂牌、日期与类似署名的语言能强化设计时，自由发明。保持它们内部连贯且原创。不要使用真实人物、制片厂、电影节或电影宣传活动的名字、logo、奖项、评级或商标身份，除非用户明确提供或要求。默认不要添加假桂冠或认证标记。

系列创作中，变化标题措辞、换行、原型、标语位置与遮挡关系。通过视觉逻辑而非重复文案来保持家族感。

## 5. 让标题成为专有电影标识

标题是唯一的主导文字声线。把它当作被设计的标识，而不是打出来的文字。

### 选一种类型声线

从场景前提选一个主要方向：

- 古典衬线或克制 Didone，用于历史、记忆、权威或浪漫；
- 压缩怪诞或板状衬线，用于城市压力、犯罪、动作或对抗；
- 几何无衬线配宽字距，用于科幻、距离、现代性或安静张力；
- 人文衬线或柔和无衬线，用于亲密、旅行、观察或温暖；
- 定制混合或精心改动的字形，用于超现实、诡异或暧昧场景。

整幅海报至多使用两个字体家族：一个标题家族、一个支撑家族。等宽或超压缩字体只可出现在微信息中，并算作支撑系统的一部分。

### 定制而不耍花招

- 修改 1–3 个有意义的细节：切口、连字、横笔、字怀、延伸或压缩连接。
- 基于可见场景结构（如屋脊线、窗节奏、道路、阴影或剪影）做修改。
- 保持标题即时可辨。不要扭曲每个字母。
- 避免通用金属效果、霓虹、斜面、发光、激进脏污、无谓描边或复制系列风格。

### 尺度与换行

- 让标题占据一个决定性场，并在缩略图尺寸三秒内可读。
- 两行标题时，让换行具有语义或节奏；绝不意外留下弱孤词。
- 用紧行距获得重量与纪念碑感；仅为安静或距离才用开放行距。
- 把标题宽度对齐到有意义的边界：肩宽、立面、地平线段、道路开口、演职员表块或刻意的画布出血。
- 若把字母裁出画布，保持单词可恢复，并保留其独特字形。

## 6. 建立自适应电影层级

从这些相对字高区间起步，并按构图调整：

| 层级 | 角色 | 标题=100 时的相对高度 |
|---|---|---:|
| L1 | 电影标题 | 100 |
| L2 | 身份/署名或行动标记 | 20–32 |
| L3 | 标语或上下文行 | 12–20 |
| L4 | 氛围元信息 | 8–12 |
| L5 | 电影微文案 | 5–9 |

- 让相邻层级明显不同。不要创造许多近乎相等的尺寸。
- 只保留一个 L1 元素。
- 除非标题有意从属于标志性主角图像，否则至多一个 L2 簇。
- 不要强行用满五个层级。稀疏预告用三层，大多数个人照片海报用四层，仅当图像能承载密集微文案时才用五层。
- 按视觉功能而非字面电影行业标签判断层级。

## 7. 指导文字与图像的关系

每个文字元素占据其位置都必须有理由。

### 保护语义关键

- 保持人脸、眼睛、关键手势、地标冠部、主要装饰、可读源标识与产品标记不被遮挡。
- 绝不要把一个字怀、横笔或一行微字放在眼睛或嘴巴上。
- 在主角最具识别性的特征周围保留干净的识别走廊。

### 用张力使用负空间

- 小字只放在局部安静、有足够对比与呼吸空间的细节上。
- 当大标题能连接构图时，让它桥接两个区，但把其关键字形放在更安静的段落上。
- 不要仅仅把文字居中放在空白里。用对齐、接近或方向对抗把它连接到主角。

### 跟随或对抗场景力

- 当支撑文字对齐到真实地平线、立面、路缘、窗节奏或透视轴能增加连贯时，就这么做。
- 除非对角线有结构依据，否则保持标题基线光学水平。
- 仅当反方向能创造刻意张力而非意外歪斜时，才使用反方向。

### 创造选择性深度

- 把大多数标题笔画放在一个深度平面上。
- 当身份需要时，允许选定的主角边缘从标题笔画前方穿过。
- 让选定的标题笔画回到安静主角区域上方，完成编织。
- 至多 1–3 个有意义的遮挡时刻。太多交替遮罩看起来破碎。
- 保持所有支撑小字完全可读；不要把微文案编织进繁忙主体。

### 局部管理对比

- 从照片取样标题颜色，或使用克制的补色。先降低饱和度，再增加暗度。
- 通过明度对比、位置与克制不透明度保持标题可读——而不是阴影或框。
- 大多数小字用一个安静中性色，行动标记至多一个强调色。
- 在灰度与缩略图尺寸下测试海报。如果标题消失，就改变位置、明度或字重。

## 8. 构建电影小字

### 身份/署名

- 用大写或小型大写配宽字距，字重比标题轻。
- 把 1–3 个虚构名字、别名或上下文短语排成一条有节制的行或均衡的单元。
- 即使它横跨海报宽度，也保持其层级从属。

### 标语

- 把标语当作安静的声音，而不是第二个标题。
- 用一到两行短行，周围留足空间，无装饰效果。
- 通过接近标题或主角视线把它连接到前提，但不要拥挤任何一方。

### 电影微文案

- 仅当密度能改善构图时才用。它是图形信息肌理，不是真实制作的证明。
- 用超压缩、可读的支撑字体排块，紧行距、受控词距。
- 当渲染器能保留区分时，让虚构角色更小、发明的名字或场景词稍大。
- 把它塑造成紧凑的灰色肌理，上下边缘干净。
- 把它的宽度对齐到标题、下图像边界或中轴。
- 让它远离密集铺地、树叶、人脸、车辆或高对比肌理。
- 除非明确要求，否则不添加 logo、桂冠或评级标记。

### 行动标记

- 用呼吸空间把它与微文案块分开。
- 让它比微文案更可见，但明显从属于标题。
- 通过尺度、字重或字距强调提供或发明的日期/码——而不是多种颜色或效果。

## 9. 克制使用触感材料

- 构建 2–3 色低饱和文字调色板：一个标题墨色、一个安静中性色、可选一个克制强调色。
- 仅当支持场景时，才在大标题字形内部应用宽纸纤维与浅活版变化。
- 小字形用更细颗粒或干净墨色，以保持可读。
- 所有纤维、压凸与不规则都精确终止于字形边缘。
- 不应用全局肌理，不强迫无关元素共享一种材料。

## 10. 编织图层

在局部自适应这个概念顺序：

1. 未改动的 `LOCKED SOURCE PHOTO`；
2. 标题与支撑排版；
3. 选定的主角边缘在标题上方；
4. 选定的标题笔画在安静主角区域上方；
5. 完全可读的微文案与行动标记（如使用）。

不要添加框、面板、矩形、圆、边框、贴纸、胶带、假桂冠、假奖项、装饰符号或无关图形。

## 11. 构建生成 prompt

每个执行 prompt 必须明确陈述：

- 精确的裁切决策与所有 `LOCKED SOURCE PHOTO` 不变量；
- 电影前提、视线顺序、主角保护区、安静场与场景轴；
- 所选戏剧布局原型及其适配理由；
- 精确标题、标题家族类别、定制字形决策、换行、尺度、位置、对齐边界、颜色与可读策略；
- 每个包含的小字角色的精确措辞与位置，包括任何发明的名字、厂牌、日期或码；
- 所选的 3–5 级视觉层级；
- 每个预期的标题–主角接触，包括哪些边缘在前方；
- 局部对比策略、仅字形肌理、灰度检查与缩略图检查；
- 禁止复制电影品牌、未请求的真实世界身份或 logo、全局肌理、场景编辑、额外形状、粘贴裁切、描边、发光、阴影、斜面与水印。

## 生成工作流

1. 检查用户提供的照片；若源图是本地文件路径，先把它上传为图片 URL，供生图工具引用（本地资源必须先转成 URL 才能作为参考图）。
2. 锁定摄影底版：竖版输入用最小安全裁切达到 3:4，非竖版保留原比例；照片除字形遮罩外保持完全不变。
3. 写电影构图地图，识别主角、视线顺序、安静场、场景轴与文字场。
4. 选一种戏剧布局原型。
5. 构建自适应电影文案库，选 3–5 个角色（标题必需），自由发明虚构名字与厂牌，不使用真实世界身份。
6. 让标题成为专有电影标识：选类型声线、定制 1–3 个细节、定尺度与换行。
7. 建立 3–5 级视觉层级。
8. 指导文字与图像关系：保护语义关键、用张力使用负空间、跟随或对抗场景力、创造选择性深度、局部管理对比。
9. 构建电影小字（身份/署名、标语、微文案、行动标记）。
10. 克制使用触感材料，肌理仅在字形内。
11. 编织图层顺序。
12. 编译生成 prompt，明确所有不变量与禁止项。
13. **调用生图工具**：使用 `image_edit`，把源图 URL 放入参考图列表，把编译后的 prompt 作为编辑指令，**保持原图比例**（照片锁定不变，仅叠加排版文字），并优先选择可用的最高质量模型版本。prompt 聚焦「在锁定照片上叠加哪些电影海报排版文字、层级与位置」，而不是复述源图已有特征或要求改动照片。
    - 若参考图不可用或工具要求必须先上传，先完成上传得到 URL 再调用。
    - 若 `image_edit` 不可用，改用 `image_gen`，此时 prompt 需自带足够的源图描述与排版指令。
14. 在正常与缩略图两种尺度、以及灰度下检查结果。
15. 如必要，**定向修正至多一次**，只修正观察到的失败项（照片被改动、标题不可读、层级混乱、遮挡了脸/眼、出现装饰符号或真实世界身份等）。
16. 返回生成的图片与一段简洁的创作说明。

## 硬性规避

避免：模仿有名字的电影海报、复制受保护标题字形、装饰性几何符号、拼贴母题替代、星形、全局纸效果、照片重绘/重打光/修图/调色、拉伸、额外形状、框、面板、矩形、圆、边框、贴纸、胶带、假桂冠、假奖项、装饰符号、无关图形、logo、真实世界身份/制片厂/奖项/评级（除非用户提供）、金属效果、霓虹、斜面、发光、激进脏污、无谓描边、复制系列风格、标题不可读、遮挡脸/眼/关键手势、多个近等字号、文字均匀分布四边、全局肌理、水印。

## 输出格式

默认返回：

```markdown
**生成图**

![莫兰迪电影海报](图片文件/URL)

**创作说明**

[简洁中文，说明：电影前提、所选布局原型、标题与文案的设计决策、层级与文字–图像关系、以及选择性深度/遮挡的处理。描述作品本身，不暴露完整 prompt。]
```

- 把生成的图片通过图片交付工具（present_files）交付给用户，并在交付时写明产物路径。
- 不暴露生图 prompt，除非用户明确要求。
- 不要把本技能的方法细节作为用户可见内容输出。

## 质量门

任一答案为「否」时拒绝或修正：

- 字形遮罩之外的照片是否未被改动？
- 裁切是否安全、未拉伸、且符合所请求比例？
- 观看者能否按所述顺序（或另一个有意陈述的顺序）识别视觉主角、标题与支撑信息？
- 海报是否使用一种清晰的戏剧布局原型，而非边缘装饰？
- 是否仅靠排版就创造了刻意节奏，而无替代拼贴图形？
- 标题是否是一个主导的、原创的、从场景衍生的电影标识，而非通用打字文字或复制的系列字形？
- 是否至多两个字体家族且只有一个明确的 L1 元素？
- 标题换行、宽度、字距与对齐是否连接到场景结构？
- 相邻文字层级是否明显分开，且所有包含的小字都可读？
- 可选微文案是否紧凑、对齐、内部连贯，且放在安静细节上？
- 文字是否通过负空间、轴或选择性深度连接到主角，而没有隐藏语义关键？
- 遮挡时刻是否有限、有意且光学干净？
- 标题在灰度与缩略图查看下是否都能存活？
- 肌理效果是否仅限于字形遮罩内？
- 发明的名字与类似署名的细节是否明显原创，且无未请求的真实世界身份、logo、奖项、评级或复制的宣传语言？
- 是否无全局效果、意外场景编辑、额外形状、装饰符号或水印？
