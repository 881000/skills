# 混凝土结构施工图

基于《22G101 混凝土结构施工图平面整体表示方法制图规则和构造详图》三册全文知识库。用于检索图集原始条文、数值与构造做法，并忠实引用原文作答。

## 核心原则（必须遵守）

回答任何图集相关问题，必须遵守"以原文、不修改不删除"：

1. **以原文为准**：数值（保护层、锚固长度、搭接长度、加密区范围等）、构造要求、制图规则条文，一律按图集原文引用，不得自行修改、删减或凭记忆补写。
2. **原始资料摘要**：给出忠实于原文的摘要——先用一句话/要点概括结论，再原文照录关键数值与构造要求；原文未写的内容不得添加，原文有但未检索到的内容不得凭经验补足。
3. **标注出处**：每条引用注明「分册（22G101-X）+ PDF页 + 图集页/图号」，如「见 22G101-1，PDF页68，图集页2-2，受拉钢筋基本锚固长度 Lab 表」。
4. **不确定即标注**：文本由 PDF 自动提取，图纸页与表格页存在噪声/缺字时，标注「提取可能有噪声，建议按页码回源 PDF 核对」，绝不把疑似错误当原文作答。
5. **图纸以图为准**：构造详图为图纸，文本层信息有限；涉及图形类构造（如某节点钢筋弯折位置、锚固形式）时，检索文本后指引用户查看源 PDF 对应页的详图。

## 知识库结构

`references/` 目录下：

- `INDEX.md` —— 三册图集的分级目录索引（章节 → 图集页 → PDF 页对照、常用表格定位速查），**检索第一步先读它**。
- `22G101-1 框架、剪力墙、梁、板.txt` —— 现浇混凝土框架、剪力墙、梁、板（148 页）。
- `22G101-2 板式楼梯.txt` —— 现浇混凝土板式楼梯（92 页）。
- `22G101-3 独立基础、条形基础、筏形基础、桩基础.txt` —— 独立/条形/筏形/桩基础（132 页）。

每个分册文件内以 `--- PDF页N ---` 分隔每页，N 为 PDF 物理页号。

## 检索流程（必读）

回答任何混凝土结构施工图问题，按以下顺序：

1. **读索引定位**：Read `references/INDEX.md`，按问题主题定位到分册、章节与 PDF 页。例如"锚固长度"→22G101-1 PDF p68-69；"楼梯滑动支座"→22G101-2；"桩顶与承台连接"→22G101-3 PDF p104-105。

2. **关键词检索**（推荐）：
   - `python scripts/kb_search.py <关键词...> [--volume 1|2|3] [--ctx N] [--limit N]`
   - 多关键词默认要求**同一页同时出现**（AND）；需要模糊匹配加 `--any`。
   - 也可用 Grep：`Grep pattern="关键词" path="references/22G101-1 框架、剪力墙、梁、板.txt" -A 3 -B 3 -n`。

3. **读取目标片段**：用 Read 打开对应分册文件，从命中行附近读取完整段落/表格。**不要整册通读**，只读目标区域（每册约 100~285KB）。

4. **引用原文作答**：按"核心原则"组织回答——摘要 + 原文关键数值/要求 + 出处（分册、PDF 页、图集页/图号）。

## 原文图片提供（图纸/表格原图）

图集以图纸和表格为主，文字提取存在噪声；凡涉及**构造详图、数值表格**，或文字命中不确定时，应同时向用户提供**原文图片**（源 PDF 对应页高清图）：

1. **何时提供**：用户询问某构件构造详图、需要看表格原样、文字提取有噪声需核对、或用户明确要求看图时，均生成原文图片交付；其他常规规则条文问答可不强制配图。
2. **生成方式**：
   - `python scripts/pdf_page_to_image.py --volume 1|2|3 --pages <页码> [--dpi 200] [--out <目录>]`
   - 页码为 PDF 物理页（用 INDEX.md 定位）；连续范围如 `68-70`，多页如 `68,70,72`。
   - 图纸细节多时用 `--dpi 200`（默认 150）。
3. **交付**：用 present_files 将生成的 PNG 逐一交付给用户，并在文字摘要中标明出处（如"见图集页 2-2，22G101-1 PDF 页68 原文图片"）。
4. **注意**：原文图片直接来自源 PDF 页面，忠实于图集原貌（含图名、图号、审核栏、页脚页码），是"以原文、不修改不删除"的最直接体现；图片应配合文字摘要一起给出，而不是替代文字检索。

## 使用示例

- 「HRB400 钢筋在 C30 混凝土、抗震等级二级时的锚固长度」→ `kb_search.py 受拉钢筋抗震锚固长度 --volume 1` → Read p69（图集页 2-3，LaE 表）作答。
- 「剪力墙水平分布钢筋的端部做法」→ `kb_search.py 剪力墙 水平分布钢筋 --volume 1`。
- 「AT 型楼梯适用条件与配筋构造」→ `kb_search.py AT 楼梯 --volume 2` → 结合 p17 表 2.2.1 与 p38 构造图作答。
- 「独立基础底板配筋长向在下还是短向在下」→ `kb_search.py 底板 双向 长向 --volume 3` → 原文为「独立基础底板双向交叉钢筋长向设置在下，短向设置在上」，注明出处 22G101-3 PDF p77，图集页 2-11。
- 「桩顶嵌入承台的深度」→ `kb_search.py 桩顶 嵌入 --volume 3` → 原文：桩直径或截面边长小于 800mm 时嵌入 50mm，≥800mm 时嵌入 100mm（22G101-3 PDF p104-105）。

## 注意事项

- 文本由 PDF 自动提取，存在 OCR 噪声：如 `d` 被识别成 `〃`/`rf`、数字偶有缺损、表格行列可能不完整。**涉及关键数值时，务必结合上下文核对，并注明出处页码，建议回源 PDF 复核。**
- 图纸页（标准构造详图）的文字层主要是图名与标注标签，逐字竖排、噪声大；构造细节以图为准，文本不足时明确指引查看源 PDF 对应页。
- PDF 页与图集页不同，换算关系见 INDEX.md「页码约定」：22G101-1/2 第一部分 图集页+14=PDF页、22G101-3 第一部分 图集页+15=PDF页；第二部分 22G101-1/3 图集页+66=PDF页、22G101-2 图集页+30=PDF页。
- 22G101-2 的楼梯平台板、梯梁、梯柱注写方式参见 22G101-1（图集原文 2.1.1 条）。
- 本技能只依据所收录的三册 22G101 图集原文作答；图集之外的规范要求（GB 50010、GB 50011 等）仅在图集原文引述时提及，不越界补充。

## 脚本说明

- `scripts/kb_search.py` —— 知识库关键词检索（日常使用）。
- `scripts/pdf_page_to_image.py` —— 从源 PDF 导出指定页为高清原文图片（图纸/表格原图，供交付用户）。
- `scripts/extract_kb.py` —— 从源 PDF 重建三册文本知识库（一次性维护用，一般无需执行；运行前需在脚本中指定源 PDF 路径）。
